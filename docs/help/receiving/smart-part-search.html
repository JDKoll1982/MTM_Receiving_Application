Smart Part Search

If you type a Part ID that doesn't exactly match anything in the system, the app doesn't just give up — it automatically finds the closest matches and shows you a Select Part dialog so you can pick the right one. This page explains when that dialog appears, how to use it, and what to do when none of the suggestions look correct.

When does this appear?

The Smart Part Search dialog opens automatically during Non-PO receiving in the Guided Wizard. Here is the exact sequence:

  1. You click Switch to Non-PO on the PO Entry screen.
  2. You type a Part ID in the Part Identifier field.
  3. You click Look Up Part (or press Enter).
  4. The app searches InforVisual. If the Part ID you typed is not an exact match — for example, you typed MMCCS instead of MMCCS00740 — the app does not show an error. Instead it finds all parts whose IDs start with or closely resemble what you typed and opens the Select Part dialog.
ℹ️
This only happens in Non-PO mode. When you enter a PO number and click Load PO, the app loads whatever parts InforVisual has on that PO — the Smart Part Search dialog is not involved.

The Dialog — Step by Step

Here is what the Select Part dialog looks like and what each part of it does:

Example: typing "MMCCS" found 2 similar parts

Part of the dialog What it means / what to do
Message at the top Tells you what Part ID you typed and confirms no exact match was found. This is normal — it just means you typed a partial or slightly different ID.
"Type to narrow results…" box Start typing any part of the Part ID or description to filter the list in real time. Useful when there are many matches and you need to narrow it down quickly.
Part list (rows) Each row shows a Part ID and a short description. Click a row to select it — it highlights yellow/gold. You can only select one row at a time.
Match count Shows how many similar parts were found (e.g., "2 matches"). If this is a large number, use the filter box to narrow it down.
Select button (blue) Confirms your choice and loads the selected part into the Available Parts table on the PO Entry screen. Only active once you have clicked a row to highlight it.
Cancel button Closes the dialog without selecting anything and returns you to the PO Entry screen so you can retype the Part ID.

How to use it

1

Read the message and scan the list

Confirm the Part ID shown in the message matches what you intended to type. Look at the list of similar parts and find the one that matches the part label on the physical delivery.

2

Filter if the list is long

If there are many suggestions, type a few more characters in the Type to narrow results… box — the list updates instantly. For example, if the physical label says MMCCS00740, typing 740 in the filter would show only that part.

3

Click the correct row, then click Select

Click the row that matches your physical part. The row highlights to confirm your selection, and the Select button becomes active (turns solid blue). Click Select to confirm.

⚠️
Always verify before clicking Select. Match the Part ID and the description against the physical delivery label. Selecting the wrong part will assign receiving labels to the wrong item in the system.

What if none of the suggestions look right?

Click Cancel to close the dialog without selecting anything. You will be returned to the PO Entry screen where you can try again.

Try these steps before contacting a supervisor:

  • Re-check the part label. Copy the Part ID exactly as it appears on the physical label — including dashes and capitalisation.
  • Try a shorter search. Type only the first four or five characters of the Part ID so the app casts a wider net of similar results.
  • Try a PO search instead. If the delivery came with a PO number, switch back to PO mode (Switch to PO Entry) and load the PO — the correct part will appear automatically in the Available Parts table.
🚫
Do not guess. If you cannot find an exact or clearly correct match, stop and contact your supervisor. Receiving a part under the wrong Part ID causes inventory errors that are difficult to correct later.

Common Questions

Will this dialog ever appear when I'm using a PO number?
No. The Smart Part Search dialog only appears in Non-PO mode when you type a Part ID directly. When you use a PO number the app looks up the parts attached to that specific PO and does not do a similarity search.
What does "derived from receiving history" mean in the description?
Some suggestions come from parts that have been received before under a similar Part ID. The system remembers past transactions and includes them as suggestions. Always verify against the physical part label — do not rely on the description alone.
The dialog showed 0 matches. What do I do?

If no similar parts are found, the dialog shows "0 matches" and the Select button stays disabled. Click Cancel and try the following:

  • Re-check the Part ID from the physical label for typos.
  • Try entering fewer characters — a shorter prefix casts a wider net.
  • Switch to PO mode if a PO number is available on the delivery paperwork.
  • Contact your supervisor if the part still cannot be found.
I accidentally clicked the wrong row. Can I change my selection?
Yes — just click a different row in the list. The highlight moves to the new row and the Select button will confirm that row instead. You can also click Cancel to start over.
How many results can the list show?
The list will show all parts that closely match the characters you typed. If the list is long, use the Type to narrow results… filter box to reduce it to the specific part you need.
