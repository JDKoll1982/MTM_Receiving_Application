🎓 End-User Help

Choosing a Receiving Mode

When you open the Receiving module, the first screen lets you pick how you want to receive parts today. Each mode is designed for a different workflow. This page explains every option so you can pick the right one and get started fast.

Overview

The Mode Selection screen is the entry point for all receiving work. It shows three large mode cards and one utility action below them. Simply click the card for the mode you want to use — the app navigates to that workflow immediately.

Mode Selection screen — click any card to enter that mode
ℹ️
Your default mode loads automatically. If you have set a default mode, the app may navigate straight to it on launch, skipping this screen. You can always return here via the Mode Selection button at the bottom of any wizard step.

The Three Modes

Each mode is designed for a specific type of receiving work:

✏️
Guided Wizard
Step-by-step walk-through — best for standard daily receiving. The app prompts you at every stage.
📋
Manual Entry
An editable grid for bulk entry. Best when receiving many lines or doing corrections.
🖊️
Edit Mode
Opens previously saved loads so you can update quantities or fix mistakes — without creating new entries.
⚠️
Not sure which to use? Start with Guided Wizard. It walks you through every field and won't let you skip a required step.

Guided Wizard

The Guided Wizard is the recommended mode for most operators. It takes you through receiving one step at a time — PO lookup, part selection, quantity entry, and label printing — so nothing gets missed.

When to use it

  • Receiving parts against a Purchase Order (most common)
  • Receiving Non-PO items by Part ID
  • Any time you are new to the receiving process
  • Any time a Quality Hold part may be involved
✅
The Guided Wizard automatically detects Quality Hold parts and requires a two-step acknowledgment before you can continue. You cannot accidentally bypass this step.

→ See the PO Entry step-by-step walkthrough

Manual Entry

Manual Entry gives you a spreadsheet-style grid where you can type values directly into rows. This is faster when you have a large batch of line items and prefer to enter them all at once rather than going step-by-step.

When to use it

  • Receiving many line items at once (bulk receiving)
  • Correcting quantities on multiple lines quickly
  • Users who prefer typing over wizard-style navigation

Edit Mode

Edit Mode opens existing receiving loads so you can make changes. It does not create new loads — it only lets you modify ones that have already been saved.

When to use it

  • Fixing a quantity entered incorrectly earlier
  • Updating a load that was partially received
  • Reviewing and correcting loads before finalising
⚠️
Edit Mode cannot be used to add new receiving lines to a PO. To add new lines, use Guided Wizard or Manual Entry instead.

Setting a Default Mode

Each mode card has a Set as default mode checkbox directly beneath it. Checking this box saves your preference so the app remembers it the next time you log in.

1

Find the checkbox below your preferred mode card

The checkbox labelled "Set as default mode" sits directly below each mode button.

2

Check the box

Click or tap the checkbox. A blue checkmark confirms it is saved. The other two mode checkboxes will automatically uncheck — only one default is allowed at a time.

3

The app remembers your choice

Your default is saved per user account. Other operators logged into the same computer will keep their own default settings.

ℹ️
To clear your default, simply uncheck the box. The app will then always show the Mode Selection screen when you open Receiving.

Reconcile Saved Locations from InforVisual

The Reconcile Saved Locations from InforVisual button runs a special process that checks each saved load against InforVisual's transaction history and current inventory.

The Reconcile button spans the full width below the three mode cards

What does it do?

When quantities in InforVisual exactly match what is saved locally, the app automatically places the load and marks it as reconciled. Loads with mismatched quantities are left for you to review manually.

⚠️
Only run Reconcile when instructed by your supervisor. This action updates load placement records and cannot be undone automatically.

When to use it

  • After a system outage that may have left loads in an unresolved state
  • During end-of-shift reconciliation as directed by your warehouse manager
  • When InforVisual and the app appear to show different quantities for the same PO

Common Questions

I don't see the Mode Selection screen — the app jumped straight into a workflow.
You or a previous user has set a default mode. Look for the Mode Selection button in the bottom-left corner of the current view and click it to return to this screen.
Can I change my default mode at any time?
Yes. Return to Mode Selection at any time, check the box under the mode you want as your new default, and the change is saved immediately.
What happens if I check two default boxes?
The app only allows one default at a time. When you check a new box, the previously checked box is automatically unchecked.
I selected a mode by mistake. How do I go back?
Click the Mode Selection button in the bottom-left corner of the wizard screen. If you have entered any data, you will be asked whether you want to discard it before returning.
Does the mode setting affect other users on this computer?
No. Default modes are stored per user account. Each person who logs in has their own independent default preference.
