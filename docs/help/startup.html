Starting the App

When you launch the MTM Receiving Application a startup screen appears while the app loads in the background. This page explains what that screen shows, what the progress messages mean, and what happens when the app finishes starting — especially if you are logging in for the first time on this computer.

What You See

While the app is loading you will see a startup window with the MTM logo, the application name and version, a short status message, and a blue progress bar.

The startup screen — you do not need to click anything

ℹ️
You do not need to do anything during startup. The app handles everything automatically. Simply wait for the progress bar to complete and the main window to open.

Status Messages

The text underneath the progress bar changes as the app moves through each startup step. Here is what each message means:

Message you see What the app is doing
Initializing… Setting up internal components — this is the very first step.
Loading settings… Reading your saved preferences and application configuration.
Connecting to database… Establishing a connection to MySQL and verifying the InforVisual (ERP) database is reachable.
Loading label templates… Preparing the LabelView templates used for printing receiving labels.
Creating user session… Looking up your Windows login in the user database and building your session profile.
Ready Startup complete — the main window is about to open.
⚠️
The startup screen stays open for longer than usual? If the progress bar stalls for more than 20–30 seconds on Connecting to database…, the app may not be able to reach a required database. Check that you are on the plant network (or VPN) and let your supervisor or IT know.

First Time on This Computer?

When the app reaches Creating user session…, it checks whether your Windows username already has a profile in the receiving database.

  • Returning user — your profile is found and the app opens the main window straight away.
  • First time on this computer — no profile is found for your Windows username, so the app automatically opens the New User Entry form where you enter your name, employee number, department, shift, PIN, and InforVisual credentials.
📋
New User Entry will open automatically — you do not need to find it yourself. Have your employee number, shift, department, and InforVisual (ERP) username and password ready.

Common Questions

The startup screen appeared and then disappeared. Is something wrong?
No — that is normal. The startup screen closes automatically once the app is fully loaded and the main window is ready. If the main window did not appear after the splash screen closed, check the Windows taskbar; the app may have opened behind another window.
After startup, a "New User Entry" form opened. What do I do?
The app could not find a profile for your Windows username so it launched the setup form automatically. Fill it in to create your account. See New User Setup for a step-by-step guide.
The app shows an error during startup instead of opening normally.

Common causes:

  • Not on the plant network — the app needs to reach the MySQL and InforVisual servers. Make sure you are connected to the plant LAN or the company VPN.
  • Database server is down — contact IT to check server status.
  • App needs to be re-installed — if the error mentions a missing file, contact IT for a fresh installation.
How long should startup normally take?
On a healthy network the startup screen should complete in under 10 seconds. If it consistently takes longer, report it to IT so they can check database connection performance.
