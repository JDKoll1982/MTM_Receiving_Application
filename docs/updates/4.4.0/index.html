MTM Receiving Application

Version 4.4.0

This release makes it faster to work a whole section of the warehouse at once. Scanner can now load every location between a start and a stop location in a single pass, and it answers Infor Visual's "assign this part to a location" prompts for you while a transfer is being saved. The Material Availability Board groups results into one collapsible section per location and accepts a location range too, and its printed Transaction Sheet is rebuilt as one clean table per part for handwriting. Every location box in the application now follows one shared rule, so the same text always resolves to the same location no matter where you type it.

Highlights

What is new in 4.4.0

Scanner works a whole location range

Switch Search By to Location, turn on the Location range toggle, and type a start and stop location. Scanner loads the parts found in every real location between them in one pass, with each location shown in its own card and a Select All button to take them all.

Availability Board grouped by location

Searches by warehouse location - including a range - now group results into one collapsible section per location, with the location and its part count in the header. Sections you are not working can be folded away while their headers stay in view.

Locations resolve the same everywhere

One shared rule now formats every location box, so va001, V-A001, and VA-A0-1 all become V-A0-01, and shorter forms like r04 become R-04 - the same value whether you type it in Scanner, on the board, or in a lookup.

What changed

Details of this release

Scanner loads every location in a range at once

The Workbench gained a location range mode. Flip Search By to Location and turn on the Location range toggle; the single location box is replaced by Start location and Stop location. Type the range and press Enter or click Load Range.

Both bounds are auto-formatted. If the start location sorts after the stop location the two are swapped automatically, and only locations that actually exist in Infor Visual are returned, so gaps in the warehouse map are skipped instead of inventing empty locations. A range is capped at 60 locations - a wider range loads the first 60 and says so in the status bar.

Each location is shown in its own compact card, with a Select All button that covers every card at once. Every row keeps the source location of the part it came from, so one range can feed rows from several locations. Switching Search By back to Part turns the range off and restores the single part-number box.

Material Availability Board groups results by location

The board's Warehouse Location mode now accepts a range of locations instead of a single one, so a whole aisle or rack bank can be reviewed in one search. Turn on the Location range toggle, type the range, then press Enter or click Load Range.

Results are grouped into one collapsible section per location. Each section header shows the location ID and how many parts were found there, and the section can be collapsed or expanded by clicking the header. Every section starts expanded, and padding and row spacing are kept tight so more locations fit on screen at once.

Look Ahead applies to every location in the range, and a location with no positive-quantity parts is skipped rather than producing an empty section. Print uses the range as the report's search term, so the printed header reads V-A0-01 to V-A0-05; collapsing a section is a screen convenience only and does not change the printout. Switching the mode to Part Number turns the range off and restores the single search box.

Transaction Sheet prints one clean table per part

The handwritten move sheet for a warehouse location is rebuilt. The sheet is now grouped by location: every part is printed under the location it was found in, and each location begins on a new page, with the page subtitle repeating that location. Five parts are printed per page so a location's blocks keep fitting one printed page.

Each part is now a single table - Qty 1 through Qty 8 across the top, four blank rows, and a smaller Total row underneath - replacing the four separate Qty/Take To pairs that used to force you to hunt across four blocks for a single move. That is sixteen handwriting cells per part.

The part card now includes the Description so the material can be confirmed without going back to the screen, and the destination location prints on its own small row above the table, which frees all eight columns for quantities. Parts with no description on file print Not available instead of a blank line.

One location rule for the whole application

Location boxes used to follow different rules on different screens, so the same typed text could resolve to different values depending on where you typed it. Every screen now uses one shared rule, so a location always resolves to the same value.

More typing styles are accepted. va001, VA001, V-A001, VA0-01, and VA-A0-1 all become V-A0-01. Shorter forms with no middle block are supported too: r04, R04, R-04, and R4 become R-04, s00 becomes S-00, and w04 becomes W-04. Any value that matches no known pattern, such as RECV, is left exactly as you typed it.

Infor Visual save dialogs are answered for you

When Infor Visual saves a transfer for a part that has never been at the destination location, it can raise two dialogs: an Inventory Transaction Entry prompt asking to assign the part to the location, and the Add Part Location form that creates the assignment.

While the Workbench is showing "Was the transaction saved in Infor Visual?", the application now watches for those two dialogs and answers them with Enter (Yes, then OK) so you can keep working. The watch polls every 300 ms, runs for at most 30 seconds, and only touches windows owned by the Infor Visual process - a same-titled window from another application is ignored. It stops as soon as you answer Yes or No, or when you leave the Workbench page.

New Scanner help pages

In-app help gained dedicated Scanner guides for the Workbench, History, and Settings, plus a Scanner overview, so operators can read up on the transfer workflow without leaving the application. Several existing help pages were refreshed at the same time.

Why it matters

What this means on the floor

Fewer keystrokes per move

A single range loads many locations at once, and the destination dialogs that used to interrupt a save no longer need a manual answer in the middle of the transfer.

Consistent location entry

The same text always resolves to the same location, wherever it is typed, so a location entered in one screen reliably matches the same shelf everywhere else.

Cleaner paper

The Transaction Sheet gives each part one table to write in and keeps each location's handwritten moves together on its own page.

What you need to do

Nothing to set up

No action is required after this update.

  • There is nothing to configure - your preferences, saved Scanner sessions, and existing records carry over unchanged.
  • Regular operators can continue using the same screens; the new location range options appear only when you turn them on.

Need help?

Reporting a problem

If a location range loads the wrong locations, a location you type does not resolve the way you expect, an Infor Visual save dialog is not answered automatically, or the Transaction Sheet is missing a part, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
