Highlights

What stands out in 4.0.0

ShipRec Customer Pull n' Pack removed

The Customer Pull n' Pack report, queue, and waitlist surfaces were removed from active ShipRec tooling in this release.

Scanner tools expanded

Scanner workbench, history, settings, validation, and item-management workflows were expanded and polished for daily use.

Faster lookup and filtering

Shared typed lookup behaviors and edit-mode date filtering were improved to reduce manual retries and speed up review tasks.

What changed

Details by area

Customer Pull n' Pack tools were retired from ShipRec

Customer Pull n' Pack report and waitlist tool surfaces were removed from ShipRec, including related queue and editor screens. ShipRec now focuses on the remaining supported tool paths.

Scanner workflow coverage expanded

Scanner history and settings workflows now include richer profile and run handling, and scanner item-management supports better batch editing behavior. Validation and workflow services were expanded to support these flows.

Receiving and Dunnage edit-mode date filtering refined

Edit Mode now includes a direct date-search button next to the date range, visible active-state highlights for preset filter buttons, and safer date-range handling for same-day and reversed-date scenarios.

Shared lookup and Dunnage column filtering usability improvements

Shared typed lookup support was expanded for part and location entry behavior, and Dunnage column filtering now supports vertical scrolling in the chooser dialog for easier access to lower options.

No database migration step is required for this update

This release focuses on application workflow changes and UI behavior improvements. Standard update rollout can proceed without a new operator-side migration step.

Why it matters

What this means in daily work

Clearer supported tool paths

ShipRec navigation now reflects active tooling only, which reduces confusion when operators switch between modules.

Better scanner throughput

Expanded scanner history, settings, and item-management behavior helps teams complete scanner-driven tasks with fewer manual corrections.

Fewer date-filter misses

Edit-mode filtering in Receiving and Dunnage is easier to trigger and more reliable for day-based and corrected date ranges.

What you need to do

Action depends on your team workflow

If your team used Customer Pull n' Pack in ShipRec, contact support for the replacement process before rollout.

  • Receiving, Dunnage, and scanner users can continue with normal update rollout.
  • ShipRec users should verify the currently supported tools on first launch after update.
  • No additional settings migration is required for standard module use.
