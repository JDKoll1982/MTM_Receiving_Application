Version 1.3.0

Highlights

What's new in this release

Non-PO Receiving & Dunnage

Receive parts and log dunnage for jobs that don't have a purchase order. The app now remembers your preferred values per part so you don't retype them every time.

Location Reconciliation Review

Before finishing a receiving run, a new review step lets you confirm all saved locations are correct — catching mistakes before they leave the floor.

Built-in Help Center

Step-by-step guides for receiving mode selection, the guided wizard, smart part search, new-user setup, and startup are now available inside the app — no printed manual needed.

What changed

Details by area

Non-PO Receiving — receive without a purchase order

Operators can now receive parts for jobs that aren't tied to a purchase order. The new Non-PO mode accepts a free-form reference number and stores those entries in a reusable list so the same reference doesn't have to be typed again. Per-part defaults are saved automatically — the next time you receive the same part number under a Non-PO job, the app pre-fills the reference you used last time.

Non-PO Dunnage entries with per-part defaults

The Dunnage workflow now supports Non-PO entries alongside the existing PO-based flow. Just like on the Receiving side, the app remembers the last value entered for each dunnage part number so your team isn't re-entering the same information shift after shift.

Location Reconciliation Review step

A new step has been added to the Receiving workflow between saving labels and completing the job. This review screen shows all the rack and bin locations recorded during the current run so you can verify everything looks right before the job is marked complete. No data entry is required — it's a confirmation screen only.

In-app Help Center with receiving and setup guides

A Help Center is now available from within the application. The initial release includes the following guides:

  • Receiving — Mode Selection: explains Guided Wizard, Manual Entry, and Edit Mode and how to set a default mode.
  • Receiving — Guided Wizard PO Entry: walks through the step-by-step receiving workflow for PO-based jobs.
  • Receiving — Smart Part Search: explains how the part search and autocomplete features work.
  • New User Setup: guides a first-time user through configuring their profile, default modes, and printer preferences.
  • Startup & Sign-in: explains what happens at launch, how network and database checks work, and what to do if the app can't connect.
Default mode toggle no longer clears unexpectedly

In both Receiving and Dunnage mode selection screens, unchecking the "set as default" toggle on a mode that isn't currently the default used to trigger a silent save with a blank value. This has been corrected — the toggle is now ignored unless the mode being unchecked is the one that was actually saved as the default.

Faster detection of active label queues

The app now checks whether the active label print queue contains anything using a lightweight query instead of loading all queued rows first. This reduces the time spent waiting on the label readiness check during workflow startup and mode transitions.

New user setup dialog improvements

The first-run setup dialog has been updated with a cleaner layout and improved field validation. Users are now guided more clearly through each required step before the main application opens.

Why it matters

What this means on the floor

Fewer workarounds

Teams receiving parts without a PO previously had to use workarounds or skip the system entirely. Non-PO mode closes that gap so every receipt goes through the app.

Fewer location errors

The reconciliation review step gives operators one last chance to spot a wrong rack or bin before the job is closed, reducing the need to go back and correct records after the fact.

Faster onboarding

New team members and relief operators can now find step-by-step answers inside the app instead of waiting for someone to walk them through the workflow.

What you need to do

No action required

No action is required after this update.

All new features are available immediately after the update is installed. Existing workflows, labels, and user settings are unchanged. Your IT or support team handles the deployment — you don't need to do anything before starting your next shift.

Need help?

Questions or problems?

If something doesn't look right after the update, note the version number shown at the top of this page (1.3.0) and report it to your supervisor or the MTM IT support team. For step-by-step guidance on any receiving workflow, use the in-app Help Center accessible from the application's main menu.
