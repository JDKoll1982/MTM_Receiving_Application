MTM Receiving Application

Version 6.0.0

This release adds a By Receiver mode that starts the guided receiving walk from the newest receipts already in Infor Visual, moves every page's Back, Next and Save buttons into one strip at the bottom of the window, and renames Dunnage to Non-Inventoried Labels while adding image cropping, sharper previews and a full-window image viewer. The Scanner can chain the next line after a save, Receiving Analytics gains a Record Days tab, the Receiving settings hub gains a Welded Part Numbers page, and manual mode has been removed from Non-Inventoried Labels.

Highlights

What is new in 6.0.0

Start a receipt from the receiver, not the purchase order

Receiving gains a By Receiver button between Guided and Manual. It lists the newest receipts already entered in Infor Visual with their receiver number, purchase order, line, part, vendor, location, and the received, ordered and remaining quantities. Choose a row and the walk carries on at Enter Loads with the location and remaining quantity already filled in, and Back returns you to your row.

Every page keeps its buttons in the same strip

Receiving and Non-Inventoried Labels pages draw Back, Next, the save button and Help in one strip under the page content instead of inside each page. The mode buttons sit in the same strip: Ctrl+click a mode to make it your own default and a Default badge marks it for next time.

Non-Inventoried Labels, with better images and no manual mode

Dunnage is now called Non-Inventoried Labels in the app, settings, reports, reprint and help. Part and type images can be cropped with preset shapes, previews are sharper, and any image opens full window. The manual mode has been removed, so the module offers Guided, Edit and Image Search.

What changed

Details of this release

By Receiver starts the guided walk from the newest receipts

Material is often entered into Infor Visual before the loads and labels are logged here. By Receiver means you no longer have to leave the application, look up the receiver, and come back with a purchase order number in your head.

  • The list is ordered by the date the receipt came in, newest first, and never shows a receipt with no part number or no warehouse location.
  • A receiver with several lines of the same part collapses to one row, and the remaining quantity never shows below zero.
  • Type any part of a receiver number into the search box, and choose 25, 50, 100 or 200 rows per page.

On Weight/Quantity the walk warns you when the loads you entered do not add up to the receiver amount, and offers Change Values or Continue. The Heat/Lot page keeps the vendor's own column for the part, and the walk remembers the vendor from the row you chose.

One action strip carries the page buttons

The strip sits under the page content, so Back, Next, Help and the save button keep the same place on every page. Page-specific words still say what they do: Save & Finish on Enter Loads and Edit Mode, Save to Database on Review, and Start New Entry on the result page.

The Receiving mode-selection screen is gone. Receiving opens in your stored mode and falls back to Guided the first time, and the back arrow in the window header is hidden because Back lives in the strip. Shift+clicking Clear Label Data still clears every label row for users whose role allows it.

Non-Inventoried Labels drops manual mode

The module no longer offers manual entry: its button, its screen, its shortcut and its help topic are gone. The strip offers Guided, Edit and Image Search. If you previously saved Manual as your default, the module opens in Guided and remembers that instead.

Scanner Auto Mode chains the next line

A new Auto Mode switch sits in the Scanner footer after Send and is off until you turn it on; your choice is remembered. With Auto Mode on, the automation saves the line in Infor Visual for you and then waits for your answer to the usual "was it saved?" prompt.

  • Yes clears the line and sends the next one straight away.
  • No stops the run and turns Auto Mode off, so a failed save cannot repeat itself.
  • Chaining stops with a plain explanation when there are no lines left, when the next line is not ready, or when the Infor Visual window has closed.
Send waits for the Infor Visual window

Send is greyed out while Infor Visual's Inventory Transfers window is closed, and a note beside the button says why. Remove Selected is unchanged and keeps working, because it only changes this list.

A location check that cannot run no longer stops the walk

When Infor Visual cannot be reached, the guided walk continues to Review with the location you typed, instead of stopping the step. A location that is reached and not found still stops the step, and Receiving keeps its stricter behaviour so a bad location is never accepted.

Receiving Analytics gains a Record Days tab

Receiving Analytics now has a Record Days tab. It shows Busiest Days split into Top Coil Days, Top Flat Stock Days and Top Other Item Days, with the labels counted for each day, so you can see which days to plan around and where the volume really sits.

The old Trend vs Last Week card and the Compare Previous Period option were removed from the chart tab; the other totals, the date ranges and the export are unchanged.

Welded Part Numbers joins the Receiving settings hub

A new Welded Part Numbers page keeps the list of parts whose coil needs its inner diameter welded. Add a part, search the list, and remove a part you no longer run; the list is shared, so everyone sees the same part numbers.

Material Availability shows what each upcoming job takes and what is left

Every associated-part row on a Material Availability card now shows Material required for that job and Remaining after run, the projected on hand once the job has used its material. The balance turns red only when it goes negative.

  • Rows are ordered by run date, oldest first, and each row is measured against what the previous row left behind.
  • Material already staged to ship and non-conforming material are not counted as usable on hand.
  • Jobs that have already finished leave both figures blank and do not reduce the balance.
  • The printed and exported sheet carries the same two columns.
Image tools on Non-Inventoried Labels

Part and type images gain a Crop button with free, square, 4:3 and 16:9 shapes; the saved image keeps its original size and the cropped version is used for previews and printing. Thumbnails fill their cards instead of being stretched, and clicking an image opens it full window, where a click outside or any key closes it again.

Search Parts by Image now searches every field on a part, including the user-defined columns, home location, quantity type, inventory type and additional notes, and its box reads Filter by anything. A current-part card with a running Quantity Per Load total sits beside the entry forms.

Select Part sorts, filters and opens on double-click

The Select Part page gains a Recv Date column, sorts when you click a column header, and filters by on-hand stock, quality hold or a single location. Your sort and filters are remembered for you. Double-clicking a part selects it and moves to the loads in one action, still respecting a quality hold; a single click only highlights.

PO Line Spec Search lets you tick more than one status, so Firmed, Released, Closed and Cancelled can be searched together instead of one at a time.

Edit Mode finds a row by any column

The Find box on Edit Mode now offers every column a receiving row carries, including part type, purchase order line and status, due date, ordered quantity, unit, heat shape and colour, location, remaining quantity, packages per load, weight per package, package type, who created the line, and the quality-hold fields. All Fields searches them all at once, numbers match with or without decimals, and dates match either way they are written.

The Receiving Validator names the day, the run and the tally

The summary strip shows the day being reconciled and its run number, with a Copy action so you can paste the run number into a message. The line counter also carries the session tally, such as Line 3 of 12 · 2 accepted, 1 skipped. A day where every line was skipped now says it was skipped instead of claiming the lines already match, and material that disagrees with live on hand is stated plainly on the page.

Reporting fixes

The Options panel on the Reporting preview is readable in the dark theme instead of white on white. A copied End of Day report is titled as a report rather than as a preview.

Search reaches the pages you actually use

The window search box now opens Receiving Validator and the two Receiving settings pages that were missing from it, and the entry for the retired mode-selection screen is gone.

Why it matters

What this means on the floor

No purchase order number needed to start

When someone else has already entered the receipt, the pallet in front of you can be found by receiver, so you stop leaving the application to look one up and typing a number from memory.

The buttons are where you left them

One strip means Back, Next and save are in the same place on every page of both workflows, and the mode you use most can be set as your own default with one Ctrl+click.

Fewer dead ends

Send tells you when Infor Visual is not open instead of failing quietly, a location check that cannot run no longer blocks the receipt, and Auto Mode stops itself the moment a save does not happen.

What you need to do

Nothing to install or set up yourself

No action is required from operators after this update.

  • Your saved settings and preferences are kept. A Non-Inventoried Labels default of Manual now opens Guided and is remembered that way.
  • Manual mode is no longer available in Non-Inventoried Labels; use Guided, Edit or Image Search.
  • Back is offered by the strip at the bottom of the page; the arrow in the window header is hidden.
  • Auto Mode in the Scanner stays off until you turn it on in the Scanner footer, and the choice is remembered.
  • The MTM IT support team deploys the new database reporting routine. There is nothing for you to run.

Need help?

Reporting a problem

If a receiver you know exists does not appear in By Receiver, a page shows no Back or Next button, a Non-Inventoried Labels screen asks for a mode you cannot find, Send stays greyed out with the Infor Visual window open, a cropped image or preview looks wrong, the Record Days tab shows no days when you know material came in, or the application will not start from the MTM Loader, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
