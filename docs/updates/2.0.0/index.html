Highlights

What stands out in this release

Standalone module removed

The standalone Outside Service module was removed from the current release, but the ShipRec Outside Service History lookup remains available.

Cleaner settings experience

What changed

Details by area

Outside Service is no longer included in the current application release

The standalone Outside Service module and its dedicated module documentation were removed from the active release path. The ShipRec Outside Service History lookup remains in place as a read-only Infor Visual reference tool.

Core Settings user management now supports search, inactive-user filters, and account reactivation

Administrators can now search the Users page with simple field prefixes, switch between active and inactive account views, and reactivate users directly from the same screen when needed.

Settings pages were simplified across Dunnage, Receiving, Reporting, Volvo, and Core Settings

Multiple settings hubs and detail pages were cleaned up with shorter labels, tighter card heights, and less repeated page text. The goal is a faster scan path for the screens operators and administrators use most often.

Unused placeholder and developer-only settings screens were removed

Placeholder pages for inactive settings areas and the old Settings Developer Tools shell were removed so the Settings experience stays focused on the pages that are actually meant to be used.

Why it matters

What this means in practice

Less navigation clutter

Users now see a release path that focuses on the workflows the application currently supports instead of carrying extra links for features that are no longer included.

Faster account support

Supervisors and administrators can find users more quickly and restore access without jumping between multiple tools or recreating accounts.

Clearer settings screens

Shorter labels and tighter layouts reduce scrolling and make it easier to spot the setting you need to change during day-to-day support.

What you need to do

Action depends on whether your team used Outside Service

No action is required for Receiving, Dunnage, Reporting, Volvo, or standard ShipRec users.

  • If your team relied on the removed standalone Outside Service screens, contact your supervisor or MTM IT before rollout.
  • If you used the ShipRec Outside Service History lookup, it remains available in ShipRec Tools.
  • If you administer user accounts, the new search and activation controls are now available on the Core Settings Users page.
