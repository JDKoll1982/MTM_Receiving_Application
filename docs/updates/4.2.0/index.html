Highlights

What is new in 4.2.0

One consistent way to work

Edit Mode and tool screens across Receiving, Dunnage, Scanner, Reporting, Ship/Rec Tools, and Volvo now use the same compact toolbar style, with quick date filters, rows-per-page choices, and a help button on each screen.

Scanner batch entry is faster

Add several lines of the same part in one step, change quantities as you go, and use the colour-coded status icon to see exactly what to fix before sending.

New: Reprint labels

A new Reprint area groups Receiving, Dunnage, and Volvo labels together so previously created labels can be reprinted from one place.

What changed

Details of this release

Receiving and Dunnage Edit Mode are easier to use

Each Edit Mode screen now has a single, compact toolbar at the top instead of several scattered rows. Load, edit, and filter actions sit side by side as icon buttons, and the search box stretches to fill the available width so there is room to type.

Date filtering is tucked behind one button with a quick picker: choose a preset such as Today, This Week, or This Quarter, or set your own start and end dates. Dunnage Edit Mode also lets you choose how many rows to show per page, and when a search finds nothing the empty table disappears so the "no matches" message is easy to see.

Scanner batch entry handles multiple lines

In the Scanner Workbench, each line now has a status icon that is colour-coded to tell you whether the line is ready, needs attention, or is waiting for a destination. Selecting the icon opens a short explanation of exactly what to do for that line.

A + button on each line lets you add more lines of the same part at once. The original line and every new line start at a quantity of one with a blank destination, so you can type in each destination as you go. Search By and Remove Selected now sit together in the footer, with Remove Selected clearly marked.

Reporting keeps date and module choices together

The Reporting opening page combines the date range and module selection into one card. Date controls fit on a single row, with quick ranges and a check-mark button to confirm which modules have data. The preview page no longer clips its contents and stays readable as the window resizes.

Ship/Rec Tools get the same toolbar treatment

Delivery Schedule, Material Availability Board, PO Line Specification Search, Welded Coils, and Dunnage Book now use the shared toolbar card. Each keeps its own filters, search, and print options in one tidy row with help on the right.

Receiving Analytics gained quick date ranges that match the view you are in: when you are looking at History you get past ranges such as last 7, 30, or 90 days, and when you switch to Incoming you get forward-looking ranges such as the next 7, 30, or 90 days.

Volvo pages place help where you are working

On the Volvo opening page the help button now sits beside Add Part, Preview Email, View Label Data, and View History in the same toolbar card. On the Volvo history page, help sits beside the date and status filters.

New Reprint labels area

Reprint is now its own landing page in the application. Choose Receiving, Dunnage, or Volvo to find a previously created label and reprint it without re-entering the original work.

Administrator settings for database configuration

Settings includes a Database configuration area where administrators can choose which database the application uses and run reference-data sync tasks. This is intended for support staff who set up workstations, not for day-to-day operators.

Cleaner no-results and focus behaviour

Screens that show a "nothing found" message now hide the leftover empty grid so the message stands out. Help content was added or updated across Receiving, Dunnage, Scanner, Reporting, Ship/Rec Tools, and Volvo, and the Scanner supports the same keyboard input handling as the rest of the application.

Why it matters

What this means on the floor

Less hunting for the right control

Toolbars look and behave the same across modules, and help is on the screen where you are working instead of floating elsewhere.

Faster batch entry with clearer status

Adding lines of one part and knowing what still needs to be done happens without leaving the list.

Reprinting is a separate, simple step

Labels that were already created can be found again and reprinted from the Reprint area.

What you need to do

Pick up where you left off

No migration or setup step is required.

  • There is nothing to configure after this update - existing preferences and saved work carry over.
  • To try the new Scanner tools, open the Scanner Workbench and use the + button on a line to add more lines of the same part.
  • To reprint a label, open Reprint from the main menu and choose the module.

Need help?

Reporting a problem

If a screen looks wrong, a date range returns unexpected results, or Reprint cannot find a label you expect, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
