Highlights

What's improved in 2.7.5

Parent-part report grouping

Customer Pull n' Pack now keeps related request lines together under the parent part, so the report layout better matches how material is reviewed and pulled.

Correct live demand source

The Customer Pull n' Pack demand query now uses the intended customer-order site, which improves the accuracy of the live report data shown to operators.

No user action required

This patch focuses on report accuracy and connection reliability. Operators do not need to change settings or run a migration after updating.

What changed

Details for this patch

Customer Pull n' Pack lines now group by parent part

The crystal-style Customer Pull n' Pack review now groups request lines by parent part instead of splitting the same part across separate customer-order groups. The QTY TO PACK value now reflects the combined ship quantity for the grouped parent part, which makes the report easier to review before you choose locations.

Sub-part location selection now stays inside the active parent-part group

When you choose locations in the SUB PARTS ON HAND section, the selection now stays tied to the active parent-part group instead of following customer-order-only grouping. This keeps selected locations aligned with the part you are actually reviewing.

Customer Pull n' Pack demand now reads from the intended site

The live Customer Pull n' Pack demand query now uses the intended customer-order site for report data. This helps prevent mismatched or incomplete demand when the report is refreshed from the live source.

Startup now points to the shared MySQL server

Application startup now uses the shared MySQL server at 172.16.1.104:3306 instead of the old 172.16.1.104 default. The startup path still uses the existing mtm_receiving_application database that the application expects.

Why it matters

How this patch helps daily work

Clearer pull review

When the same parent part spans multiple request lines, the report now keeps those lines together so it is easier to understand the full pull picture before taking action.

Fewer misleading selections

Location choices now stay scoped to the parent part being reviewed, which reduces the chance of selecting the wrong sub-part location context.

More dependable live data

Using the intended customer-order site and the shared MySQL server improves the chances that operators see the right report data when the screen loads or refreshes.

What you need to do

No extra steps after updating

No action is required after this update.

After installing the new version, open Customer Pull n' Pack as normal. If the report still appears to use the old grouping or does not load, close and reopen the application and report version 2.7.5 to MTM IT support.
