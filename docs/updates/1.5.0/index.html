Highlights

What stands out in this release

Purchase receipt support tools

New helper scripts were added for locating and filling Purchase Receipt Entry fields in Infor Visual more consistently.

Reconciliation settings save action

The Receiving reconciliation settings page now has a visible Save button so changes can be committed directly from that screen.

Clearer process reference

A new plain-language reconciliation process guide was added to explain how the current review logic decides what needs attention.

What changed

Details by area

Receiving reconciliation settings can now be saved directly from the Reconciliation page

The dedicated Reconciliation settings page now includes its own Save button. Users no longer need to rely on a different page layout or assume the screen auto-saves after changing the history-scope toggle or ignored-location list.

New Infor Visual Purchase Receipt Entry helper scripts were added

The repository now includes new discovery and entry scripts for Purchase Receipt Entry. These tools capture the live screen layout and help populate purchase order, quantity, and location fields more repeatably during support or operator-assisted workflows.

Layout data can now be captured and reused for repeatable Purchase Receipt Entry work

A saved layout configuration file is now part of the tooling flow, which makes repeated Purchase Receipt Entry automation less dependent on stale hard-coded field handles.

Receiving reconciliation now has a simple step-by-step process guide

A new operator-friendly process page explains how the current reconciliation logic decides whether a saved row is skipped, kept unchanged, moved into review, or left for manual follow-up.

Why it matters

What this means in practice

Less guesswork in settings

The reconciliation preferences page now behaves more like the rest of Settings, which makes it clearer when a change has actually been committed.

More repeatable Infor Visual support work

The new purchase-receipt tooling gives MTM staff a more consistent way to inspect and target fields in Infor Visual when troubleshooting or assisting with entry tasks.

Easier explanation of reconciliation decisions

The new process guide makes it easier to explain why one row was auto-matched, another stayed unchanged, and another still needs manual follow-up.

What you need to do

No action is required

No action is required after this update.

If you use the Receiving reconciliation settings page, you can now save changes directly from that screen.
