What's New in 1.2.0

This update adds more control over Receiving reconciliation, makes documentation easier to reach from inside the app, and improves what users see during startup and new-account setup.

Highlights

The biggest user-facing changes in this release

Receiving control

Receiving settings now include a dedicated Reconciliation area for ignored locations and history-scope behavior.

Easier help access

Documentation is easier to reach from the app and now has clearer home and updates pages.

Startup clarity

Startup and first-time account setup now provide clearer status information, including the visible application version.

What changed

Detailed notes

Receiving Settings now include a dedicated Reconciliation page

The Receiving settings area now separates reconciliation controls into their own page. Users and support staff can manage extra ignored recommended locations and choose whether reconciliation checks all visible receiving history or stays limited to the narrower default scope.

Receiving settings navigation is more structured

The Receiving settings hub now breaks options into clearer categories, including Part Formatting and Reconciliation. This makes it easier to go directly to the setting you need instead of searching through a more general page.

Documentation is easier to open from inside the app

A Documentation entry is now available from the application navigation, and the documentation home page has been reorganized so users can move between feature guides, database reference material, and release updates more easily.

Startup and account setup feedback is clearer

The splash screen now shows the installed app version, which makes support verification easier. New-user account setup also gives clearer loading and success feedback so users know when account creation is in progress and when startup will continue automatically.

Why it matters

What users will notice

More predictable Receiving behavior

Teams can fine-tune which locations should never be suggested during reconciliation, which helps reduce avoidable location noise.

Faster self-service support

Opening documentation from the app reduces the need to hunt for local files or shared links when someone needs help or wants to review a process.

Clearer version confirmation

Support can quickly confirm whether a machine is on the expected release by reading the version on the splash screen.

What you need to do

No operator action is required

No action is required after this update.

  • If you use Receiving reconciliation, review the new settings page when you have time so you know where those controls now live.
  • If support asks which build you are running, use the version shown on the splash screen or copy the version from this page.

Need help?

Include the version if you report a problem

Contact your normal MTM support contact and include Version 1.2.0 in the message. That helps support confirm you are on the release that includes the Receiving reconciliation settings split, documentation shortcut, and startup feedback updates.
