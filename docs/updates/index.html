Latest release

Version 2.1.0 at a glance

Manual transfer table

Printed Material Availability Board cards now include a five-row handwriting table for recording manual inventory moves directly on the shop floor.

Color-coded part cards

Each unique part number on the printed board gets a consistent pastel background color across all its rows and sections for easy identification.

Cleaner load entry

The Receiving load entry form now shows quantity and location side by side, with the part number and description displayed as clean inline labels.
