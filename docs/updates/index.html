Latest release

Version 4.2.0 at a glance

One consistent way to work

Receiving, Dunnage, Scanner, Reporting, Ship/Rec Tools, and Volvo share a compact toolbar style with quick date filters, rows-per-page choices, and help on each screen.

Scanner batch entry is faster

Add several lines of the same part in one step and use colour-coded status icons to see exactly what to fix before sending.

New: Reprint labels

A new Reprint area brings Receiving, Dunnage, and Volvo labels together so previously created labels can be reprinted from one place.
