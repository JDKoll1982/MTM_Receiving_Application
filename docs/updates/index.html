Latest release

Version 2.7.0 at a glance

Reprint from History

Select any received load in History view and send it straight back to the label queue with one click — no re-entering data required.

Clear button stays active

After queuing a reprint, the Clear Label Data button re-enables automatically so you can clear the queue as soon as labels are printed.

DB migration required

An IT administrator must run migration script 09_Migration_receiving_reprint_flag.sql before the Reprint from History feature becomes available.
