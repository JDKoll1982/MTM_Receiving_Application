Latest release

Version 2.2.0 at a glance

Shared label shortcuts

Receiving, Mini-Receiving, Volvo, and Dunnage labels can now be opened from the shared left navigation footer instead of only inside individual workflows.

Faster Dunnage images

Dunnage image previews now use a local cache that is refreshed from the shared image folder, which helps screens stay responsive when the network is slow.

Smoother publishing

The publish tool can now migrate staged output to the shared deployment folder automatically and keeps the UI locked while publish or migration is still running.
