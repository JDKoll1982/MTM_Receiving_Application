Highlights

What's new in 2.7.0

Reprint from History

Find any previously received load in History view and send it back to the print queue with one click — no re-entering data required.

Clear button stays active

After queuing a reprint the "Clear Label Data" button re-enables automatically, so you can clear the queue as soon as labels are printed.

Refreshed label shortcuts

The four label-launch buttons in the navigation footer now show clear letter icons (R, R-mini, D, V) with hover highlights and visual separators.

Browse for files and folders

Every label path setting and the export root path now have a Browse button — open a file picker dialog and navigate to the file instead of typing the full path by hand.

More settings in search

Ten additional settings pages — including keyboard shortcuts, label file paths, email recipients, and LabelView — are now reachable directly from the title-bar search.

What changed

Details for each improvement

Reprint a label from Receiving History

In Edit Mode, switch the data source to History. Select any received load, then click the new Reprint button. The application copies that load back into the active label queue with a reprint marker so it will not be archived a second time when you clear the queue. Switch back to Current Labels to confirm it is there, then print as normal.

A guard prevents the same history record from being queued twice. If you try to reprint an entry that is already waiting, you will see a warning message instead.

Clear Label Data button re-enables after a reprint

Previously, if you cleared the label queue and then sent a history entry back for reprint, the Clear Label Data button remained grayed out until you navigated away and back. That is fixed — the button enables itself immediately once the reprint row lands in the queue.

Refreshed label shortcut buttons in the navigation footer

The four quick-launch buttons at the bottom of the navigation panel were redesigned. Each button now shows a bold letter icon — R (Receiving), R mini (Mini-Receiving), D (Dunnage), and V (Volvo) — on a bordered card with individual hover and press highlighting. Visual separators between the groups make scanning easier.

Reprint rows skip archival when the queue is cleared

When you clear your label queue, the application moves rows to receiving history. Rows that were queued as reprints are already in history, so they are now skipped during the archive step and only deleted — no duplicate history entries are created.

Browse button on label path settings

The Receiving Label Files, Dunnage Label Files, and Volvo Label Files settings pages previously showed an Open Folder button that opened the folder containing the configured file. That button has been replaced with a Browse... button that opens a standard Windows file picker filtered to .lbl files. Navigate to and select your label template file directly — the full path fills in automatically. The mini-receiving label path on the Receiving page has the same Browse button.

Browse button for the Export Root Path and LabelView executable

Shared Paths in Core Settings now has a Browse... folder-picker button next to the Export Root Path field so you can navigate to the destination folder instead of typing the UNC or local path.

The LabelView settings page has the same improvement: a Browse... button opens a file picker filtered to .exe files so you can locate the LabelView executable by clicking rather than typing.

Ten more settings pages reachable from the title-bar search

The application-wide search box now covers ten additional settings destinations that were previously missing:

  • LabelView (Core Settings)
  • Material Availability Fields (Core Settings)
  • Receiving Keyboard Shortcuts
  • Receiving Label Files
  • Dunnage Keyboard Shortcuts
  • Dunnage Label Files
  • Reporting Email Recipients
  • Volvo Part Catalog
  • Volvo Email Recipients
  • Volvo Label Files

Type any of the bolded terms above into the search box and the matching settings page will appear as a result.

Database update required before first use

This release adds a new is_reprint column to the receiving label data table and a new stored procedure. Your IT administrator or database manager needs to run migration script 09_Migration_receiving_reprint_flag.sql once against the mtm_receiving_application_test database before you use the Reprint from History feature.

Why it matters

How this update helps your daily work

No more re-entering data for reprints

When a label is damaged, lost, or printed incorrectly, you can now pull the original entry straight from history and send it to the printer. Every field — part number, PO, quantity, heat — comes over exactly as it was received.

Cleaner queue management

The Clear Label Data button responds immediately when a reprint is queued, so there is no awkward wait or navigation needed before you can finish clearing the queue.

Easier label file access

The refreshed label shortcut bar makes it quicker to identify and open the right label template at a glance — especially useful on days when you switch between receiving types.

No more typing long file paths in settings

Every settings field that previously required you to type or paste a full path now has a Browse button. Click it, navigate in the standard Windows dialog, and the path fills itself in. This reduces typos and removes the need to keep a separate note with file locations.

Find any setting faster

Ten settings pages that were not previously reachable via search are now indexed. You can jump directly to Keyboard Shortcuts, Label Files, Email Recipients, or the Volvo Part Catalog from the title bar without navigating through the settings hub menus.

What you need to do

One administrator step is required

A database migration must be applied before using the Reprint from History feature.

  • Ask your IT administrator or database manager to run 09_Migration_receiving_reprint_flag.sql against the mtm_receiving_application_test database.
  • Regular operators do not need to do anything themselves — just update the application and let IT know about the migration.
  • All other changes in this release (the Clear button fix and label shortcut redesign) work immediately after updating with no extra steps.
