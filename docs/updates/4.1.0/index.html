What is new in 4.1.0

Ship/Rec Tools now includes a search for purchase order line specification text, with options for ranked, partial-word, and exact-phrase matching.

What changed

Details of this release

New: PO line specification search in Ship/Rec Tools

You can now search the specification text attached to purchase order lines directly from Ship/Rec Tools, instead of opening orders one at a time to read them.

An options dialog lets you choose how the search behaves: ranked best-match results, partial word matching, or an exact phrase. You can also limit results by order status so closed or cancelled work does not clutter the list. Long specification text opens in its own reader window so you can review it comfortably.

Edit Mode remembers how you set it up

Version 4.0.0 improved Edit Mode date filtering. This release builds on that by saving the rest of your Edit Mode setup automatically as you change it: which columns are visible, which column Search By uses, the sort column and direction, and the page size.

These come back the next time you open Edit Mode, so you no longer rebuild the same view every shift.

Reporting preview keeps your preferred layout

The Reporting preview now saves your Row Display Mode along with the per-module choices: whether a module is included, which columns are shown, and how it is sorted. Reopening Reporting restores that setup instead of starting from defaults.

Rows that group multiple locations now display each location on its own line, which makes the preview table much easier to read.

Dunnage lookup and view preferences improved

The Dunnage location picker now loads a larger set of locations up front, and if what you type does not match anything on screen it automatically searches again using your typed text before reporting no matches.

Your preferred thumbnail size, part image preference, and type selection sort order are now saved to your user profile. Returning from Part Selection also correctly takes you back to Image Search when that is where you started, and the part you picked stays selected while the screen refreshes.

Fixed: clearing a load quantity stopped the application

Deleting the number in a Load quantity box could cause the application to stop responding, forcing you to close it and re-enter the loads. Those boxes now accept an empty value safely. An empty box counts as zero, so type the correct number before continuing.

The same fix applies to Receiving load entry and Dunnage quantity entry.

Fixed: keyboard focus in guided workflows

Moving between steps in the guided Receiving and Dunnage workflows now reliably puts the cursor in the field you are meant to fill in next, including when a step first becomes visible.

Navigation and behind-the-scenes updates

The Scanner entry in the main navigation is now selectable and shows a caution tooltip instead of being greyed out.

Dunnage history and Dunnage location behavior were made consistent across the workflow screens, and the underlying saved-preference storage was tightened so settings that previously did not stick now save correctly.

Why it matters

What this means on the floor

Less repeated setup

Edit Mode, Reporting preview, and Dunnage view choices carry over between sessions instead of resetting each time.

Faster specification lookups

Finding the right purchase order line by its specification text no longer means opening orders one by one.

No lost work during entry

Correcting a mistyped weight or quantity no longer risks losing the loads already entered for the part.

What you need to do

Set your preferences once

No migration or setup step is required.

  • The first time you open Edit Mode, Reporting preview, or Dunnage after the update, set the view the way you want it. It will be remembered from then on.
  • To try the new specification search, open Ship/Rec Tools and choose PO Line Spec Search.

Need help?

Reporting a problem

If a saved preference does not come back, a specification search returns unexpected results, or the application stops responding, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
