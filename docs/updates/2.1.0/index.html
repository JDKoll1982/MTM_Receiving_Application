Highlights

What stands out in this release

Manual transfer table

Every printed Material Availability Board card now includes a five-row handwriting table for recording manual inventory moves on the shop floor.

Color-coded part cards

Each unique part number on the printed board gets a consistent pastel background color so related rows and sections stay easy to follow at a glance.

Cleaner load entry

The Receiving load entry form now shows the part number and description in a cleaner two-column layout with the quantity and location fields side by side.

What changed

Details by area

Manual Inventory Transfers table added to each Material Availability Board card

Printed cards now include a five-row, pre-formatted table below the Current Locations section. Each row has columns for Time, From Location, To Location, Qty, and Initials. Rows are sized for comfortable handwriting so staff can record transfers directly on the printed sheet without needing a separate form.

Total on Hand footer row added to Current Locations table

The Current Locations table now shows a bold Total on Hand row at the bottom that sums all positive-quantity location amounts. This gives a quick check against physical counts without manually adding up each location line.

Each unique part number receives a consistent color on the printed board

Up to fifteen unique parts each get a distinct pastel background color that applies to the card header, table rows, and section titles. When more than fifteen unique parts appear, colors cycle back to the beginning. The coloring persists across all sections for the same part so the printed output stays easy to read and organize on the floor.

Incoming Material section only appears when incoming data is present

Previously the Incoming Material section was always rendered on each card, sometimes showing a blank or empty-state block. It now only appears when a part actually has incoming supply data. Cards with no incoming material are shorter and less cluttered.

Associated Parts run date now uses the correct fallback order

The run date shown in the Associated Parts table now tries the scheduled start date first, then the forecasted next due date, and shows No scheduled date only when neither date is available. This prevents blank run-date cells on cards where a scheduled start date exists.

Receiving load entry form redesigned with a side-by-side layout

The load entry screen now displays the part number as a labeled inline field and places the part description below it. The quantity and location inputs sit side by side rather than stacked, which reduces scrolling and makes the two most important entry fields easier to scan together.

Why it matters

What this means in practice

Fewer separate forms on the floor

The manual transfer table is printed directly on the Material Availability Board card, so staff can record inventory moves without carrying a separate piece of paper. At end of shift the completed card is a single document that shows both the starting state and every adjustment made during the run.

Faster quantity verification

The Total on Hand row means anyone picking up a printed card can immediately compare the system total to a physical count without doing arithmetic on the printed location lines.

Easier to follow on a busy floor

Color-coded cards let team members quickly identify which rows belong to which part at a glance, even when multiple cards are spread out on a bench or pinned to a board.

Cleaner printed output

Hiding the Incoming Material section when no supply is pending reduces paper waste and removes visual clutter from cards that would otherwise carry an empty placeholder section.

What you need to do

No action required

No action is required after this update. All changes apply automatically the next time you print a Material Availability Board or open the Receiving load entry screen.

  • If you print Material Availability Board cards regularly, the new layout takes effect immediately — no settings change is needed.
  • The transfer table rows are blank by design and intended for handwriting after printing.
  • If your printed cards look different than expected, confirm you are on version 2.1.0 by checking the About screen or asking your MTM IT contact.
