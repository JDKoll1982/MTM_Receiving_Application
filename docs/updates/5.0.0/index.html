MTM Receiving Application

Version 5.0.0

This release adds the Receiving Validator, which checks one day of receiving at a time against Infor Visual and proposes where each load really went. The guided receiving walk gains a part page and a step trail, one batch of edits can now fix many ticked rows, and the Material Availability sheet tells you how many skids or packages arrived before you start. The Visual Macro Tester has been removed, and IT now deploys database changes with a new tool that backs up first.

Highlights

What is new in 5.0.0

The Receiving Validator checks a day at a time

Open Receiving Validator from the Reporting group. It reads the receiving lines saved for one day, reads the transfers for those parts from Infor Visual, and proposes a destination for every line. It only writes a line it can fully account for, and a person accepts every write. A colour tells you where each line stands, from green for written to red for not enough material.

A part page and a step trail in the guided walk

When a purchase order carries more than one part, the guided walk now stops on a Part page: scan or type to narrow the list, read the part's details, and see a quality hold named before you reach the save. A trail across the top of the window lists every step, lights the one you are on, and shows Step 3 of 7 beside it.

Batch edit changes many rows at once

In Edit Mode, tick as many rows as you need and set Heat/Lot, Location, Package type, Packages per load, or Weight per package for all of them together. Each value is read and checked first, so a word in a whole-number field is refused with a reason instead of being saved, and nothing reaches the database until you press Save.

What changed

Details of this release

Receiving Validator replaces the old reconcile screen

The Reconcile Saved Locations from Infor Visual entry is gone from Receiving. In its place, Receiving Validator sits in the Reporting group with from Infor Visual beneath it. It opens a launcher, and Work a Receiving Day opens the working page on today.

The page works exactly one day at a time. Previous and Next skip days with no receiving, and Today brings you back. Pick a line and the right-hand pane explains what was found and fills in the proposed destination; press Enter to accept it or Escape to skip it for this session. An accepted line leaves the list at once, and a day that has been fully written says every line is done instead of showing an empty grid.

Extra material that arrived on another receipt in the same location no longer reads as surplus against your lines. When something needs a person, the Needs Attention button lights up: open it, read the reason, type the location, and set it.

The guided receiving walk has a part page and a step trail

The Part page only appears when there is something to choose. A purchase order with a single part number is selected for you and the walk goes straight to the loads; Back from the loads returns you to the purchase order in that case. Non-purchase-order receipts are unchanged, because there is no part list to pick from.

The step trail moved out of the pages and into a strip in the window header, so it stays put while you work and a clerk who walks away mid-receipt can see where they were.

Manual Entry reviews before it saves

A manual receipt used to write straight from the grid. It now runs the same row checks and then shows the Review page, which also carries the Shape and Colour cards for parts on the lot marking list. Review sends a manual receipt back to the grid and a guided one on to the Package step, so the walk remembers which door the receipt came in through.

The Shape and Colour cards are left off the entry form entirely for parts that are not on the lot marking list, so the columns reflow and the form is shorter.

Edit Mode gains a batch edit panel

Ticking rows used to be a way to remove them. The new Batch edit panel applies one value to every ticked row at once, and an unknown package type or a word in a whole-number field is refused with a reason instead of being written as a zero.

Dunnage walk shares the step trail and reads as two cards

The dunnage walk uses the same step trail in the window header, double-tapping a part card carries on the same way Next does, and the results page is drawn as two cards instead of a label-and-value form.

The Material Availability sheet names the skids or packages received

The transaction sheet now carries a Skids / packages received row for the part, counted from the board's Date Range. Leaving both dates empty counts today only; a single date counts that day; dates entered the wrong way round are swapped. When the count cannot be read the row shows n/a instead of blocking the sheet, and the old destination Location row is gone because the page subtitle already names the location.

Lot Marking search reaches part numbers

The search box now takes a heat or lot number or a part number, and the realign confirmation shows the supplier name the receipt carried instead of the supplier group.

Ship/Rec Tools is now Extra Tools

The navigation entry and its pages are renamed Extra Tools. The tools inside are the ones you already know.

A new database deployment tool for IT

Database changes are now deployed with MTM Database Deployment, a separate tool with three steps: Connect, Check, and Save. Check previews every change before anything is written, in plain language, with the technical detail available under Technical details - for IT.

  • The tool copies the target database to a backup before its first write, and a backup it cannot take stops the run.
  • A second run skips the reference data it has already applied instead of replaying it.
  • A rebuild that starts from nothing needs its own confirmation box ticked before the save button unlocks.
  • Schema scripts can now be re-applied safely, so the old migration layer is retired and is no longer deployed.
Start-up uses the spare database server when the shop server is down

When the shop database server cannot be reached, the application now tries the configured spare server instead of waiting out a long timeout for each saved setting. Start-up finishes in seconds and says which server it used. When the shop server answers, nothing is redirected.

Readability fixes

Part ids are readable in the dark theme on Enter PO, Manual Entry, and Edit Mode. Card edges are visible in both themes. The Scanner footer is one row tall, so the left and right button groups keep their places. The Current Total reminder is a card with a slow animated border instead of pulsing red text, and the image-search filters on Dunnage no longer touch each other.

Pages that are gone

The Visual Macro Tester page has been removed, along with the Visual Macro and Visual Macro Tester search entries. The database Sync Tool card is also gone from the database settings page.

Why it matters

What this means on the floor

A wrong location is either fixed or explained

The validator names what is wrong instead of saying a line is ambiguous. It either writes a location it can prove, or it tells you exactly what is missing and lets you set the location yourself.

The walk shows you where you are

The step trail and the part page mean a receipt started in the middle of a busy shift is easy to pick up again, and the part you are about to save is named before you save it.

Corrections arrive in batches

One panel fixes Heat/Lot, Location, package type, or weights on every ticked row, with the values checked before anything is written.

What you need to do

Nothing to install or set up yourself

No action is required from operators after this update.

  • Your saved settings and preferences are kept; the screens you already use behave as they did.
  • Receiving Validator is a new entry in the Reporting group. The old Reconcile entry is no longer inside Receiving.
  • Batch edits write nothing until you press Save, so a batch you abandon changes no rows.
  • The MTM IT support team deploys the database changes with the new deployment tool, which backs the database up first. There is nothing for you to run.

Need help?

Reporting a problem

If the Receiving Validator proposes a location in the wrong place, a line stays red or amber with a reason you cannot act on, a part page appears when there is nothing to choose, a batch edit refuses a value you know is correct, the Material Availability sheet shows n/a when it should show a count, or the application will not start from the MTM Loader, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
