What's New in 1.1.0

This release adds customizable keyboard shortcuts for the Receiving and Dunnage workflows, faster date filtering in Reports, and smarter navigation buttons throughout the app.

Version 1.1.0

Released April 26, 2026

Highlights

The biggest improvements in this update

Keyboard shortcuts

Both the Receiving and Dunnage workflows now support fully configurable keyboard shortcuts. Set the keys that fit your flow in Settings.

Faster reporting

Pick Today, Yesterday, or This Week from a dropdown instead of manually entering both dates — reports load with one click.

Accurate date ranges

Reports now correctly include all transactions recorded on the end date, not just those before midnight.

What changed

Details by area

Keyboard shortcuts — Receiving workflow

You can now assign custom keyboard shortcuts for the most common Receiving actions: moving to the next or previous step, jumping back to mode selection, clearing label data, and opening help. A new setting also lets you turn on simple arrow-key navigation with a single toggle (Ctrl+T by default). Go to Settings → Receiving → Keyboard Shortcuts to configure.

Keyboard shortcuts — Dunnage workflow

The same configurable shortcut system has been added to the Dunnage workflow. Assign keys for next step, back step, mode selection, clear label data, and help. Find these options under Settings → Dunnage → Keyboard Shortcuts.

Reporting — date range presets

A new dropdown in the Reports screen offers four quick presets: Custom (use your own dates, same as before), Today, Yesterday, and This Week. Selecting a preset fills in both dates automatically. You can still switch back to Custom and type any range you need.

Reporting — end-of-day records now included

Previously, reports with an end date of — for example — April 25 could miss transactions recorded in the final hours of that day. The date range logic has been corrected so the end date is now fully inclusive. If you ran reports recently and noticed missing late-day entries, re-running them will now show the correct totals.

Receiving workflow — smart navigation buttons

The Back and Next buttons in the Receiving workflow now show or hide automatically based on which step you are on. The Back button only appears when there is a previous step to return to; the Next button is only shown when moving forward is available. This removes visual clutter on the first and last steps.

Dunnage workflow — image search entry point

The Dunnage workflow now supports launching directly into Image Search mode from the workflow controller. This makes image-based part lookup accessible as a first-class step rather than a secondary action.

Dunnage mode selection — "Manual Entry" replaced with "Edit Mode"

The old Manual Entry mode tile has been replaced by Edit Mode, which is dedicated to loading and correcting historical dunnage records. The icon and description have been updated to reflect this new purpose.

Receiving — navigation guard now prevents leaving mid-save

If a receiving save is in progress when you try to navigate away, the app now shows a "Save In Progress" dialog and blocks the navigation until the save completes. Previously, navigating away too quickly could leave the workflow in an inconsistent state.

Dunnage details — location field now required before advancing

The Go Next button on the Dunnage Details Entry step is now disabled until a location has been entered. This prevents saving records with a blank location.

Splash screen — now shows the MTM logo

The loading screen that appears while the app starts up now displays the MTM logo image instead of a generic icon, giving the startup sequence a more polished, branded look.

Why it matters

What this means for your day-to-day work

Fewer hands off the keyboard

Configurable shortcuts let heavy users move through Receiving and Dunnage steps without reaching for the mouse, reducing cycle time on the floor.

Reports you can trust

The date range fix and the new presets together mean fewer re-runs and less second-guessing about whether a report captured everything it should have.

Cleaner, less confusing screens

Navigation buttons that only appear when relevant, a required location field, and a save guard on navigation reduce mistakes and make the workflows easier to follow.

What you need to do

Optional setup, nothing required

No action is required after this update. The app will open normally and all existing workflows continue as before.

  • To use keyboard shortcuts, open Settings → Receiving → Keyboard Shortcuts or Settings → Dunnage → Keyboard Shortcuts and assign your preferred keys.
  • If you run regular end-of-day reports, consider re-running any recent reports that may have been affected by the date range fix.
  • The Dunnage Manual Entry mode has been renamed to Edit Mode. If you had it set as your default, it will continue to work — the underlying function is the same.

Need help?

Something not working as expected?

Contact your MTM support contact and include Version 1.1.0 in your message. If a report looks different after this update, that is most likely the date range fix working correctly — but reach out if you are unsure.
