Highlights

What is new in 4.7.0

The colored symbol gets its own page

The results page now carries a card naming the labels whose part takes a lot shape and color. One button saves the receipt and opens the Label Overlay with exactly those lots already ticked, so the right tags come out colored.

Overlay tags in bulk, or as cut-out cards

The overlay prints to any printer you choose and remembers that printer's paper and tray for each output. It can also print cut-out cards: eight identical cards on one sheet, one sheet per lot, as many sheets as you ask for. A built-in preview shows the page before anything is sent.

Dunnage parts that need no label

A Dunnage part can be marked needs no printed label on the New Part and Edit Part screens. Its loads are saved straight to history instead of being queued for LabelView, so nothing waits in the label queue for a tag nobody prints.

What changed

Details of this release

Results pages warn when a tag still needs its colored symbol

When a receipt's part number is on the list of parts that take a lot shape and color, the Review page and the finish page now show a card listing the parts and lots involved. Manual entry saves straight from the entry grid, so its reminder appears on the finish page.

The card says the tag has to be printed in LabelView first and then printed over with the symbol. On Review the button reads Save & print symbol and saves the receipt before the overlay opens; on the finish page the receipt is already saved, so the button goes straight to the overlay. Nothing opens if the save fails.

Label Overlay prints tags and cut-out cards with your own printer settings

The overlay window now carries a footer with Advanced, Copies, Close and Print. Print opens the Windows print dialog with the printer, paper, tray and copy count you saved for that output, so a one-off change can be made without touching the saved setup.

  • Cut-out cards print eight identical cards per sheet, one full sheet per lot, repeated as many times as the duplicate count asks for. Lots are never mixed on one sheet.
  • Print preview shows the tag or the card sheet before it is sent.
  • The paper tray you pick is remembered the next time you open the window.
  • Advanced opens a small window for where the marking lands on the tag — from the left, from the top, circle size and the heading above it — which is only worth changing when a printed tag sits wrong.
Dunnage parts can be marked as needing no printed label

The New Part and Edit Part screens have a Needs no printed label checkbox. A part marked this way saves its loads straight to history, and the part's details panel says so.

The rule is per part, not per receipt, and it is matched without regard to capitals or spacing. If the list cannot be read, every label is queued as before: a label that was queued need not have been, but one that was skipped cannot be recovered.

The Lot Marking tool gained date, order and column controls

The Heat / Lot Management tool now filters the ledger by the date it was received, sorts by any column in either direction, and lets you choose which columns are shown. The change, filter and parts screens each open in their own small window instead of crowding the list.

Receiving Analytics App Data has a date range you can pick from a list

The App Data tab keeps its two date boxes but they now sit behind a Date Range button with ready-made choices: the last 7, 30 or 90 days, this month, last month, this quarter, last quarter, this year, and the last 12 months. Because App Data only reads completed receipts, every choice looks backwards.

Start-up is quicker

Preparing your settings used to ask the database for one setting at a time, about 280 reads on this manifest, and it is now read once per category. The splash screen also shows what the current step is doing, so a step that takes a few seconds no longer looks like a freeze.

A setting whose saved value could not be read was being reset on every single launch, with a warning each time. That is fixed, and the build now refuses a default that cannot be read back.

Print and window fixes around the overlay

Print is usable as soon as the overlay finishes loading, so a receipt's labels can be printed without touching a checkbox first. The paper tray you choose stays chosen. The Printer Settings page no longer overlaps its own text, the paper tray list opens, and the "eight cards to a page" line is gone from the bottom of that page.

Dialog sizing was also corrected across Scanner, Reprint and the shared dialogs, so buttons and boxes are no longer cut off on smaller screens.

Why it matters

What this means on the floor

A colored symbol is no longer forgotten

The reminder appears on the page you are already on, names the lots, and opens the overlay with those lots ticked. There is no list to retype and no tag to hunt for later.

Overlay work can be batched

One setup prints every tag or every card sheet for a run, at the copy count you choose and to the tray you saved, with a preview to check first.

Dunnage stops queueing labels nobody prints

Parts that never get a tag save straight to history, so the label queue only holds work that will actually go to LabelView.

What you need to do

Nothing to install or set up yourself

No action is required from operators after this update.

  • Every existing screen behaves as it did, so nothing has to be relearned. The Label Overlay keeps its saved setups.
  • The needs no printed label checkbox starts empty on every part. Tick it only when a part truly never needs a tag.
  • This release adds a database table and updates the label procedures that go with it. The MTM IT support team deploys those scripts with the release; there is nothing for you to run.
  • If your area prints cut-out cards to a particular tray, set it once on the Printer Settings tab and it will be reused.

Need help?

Reporting a problem

If the colored symbol reminder names the wrong lots, the overlay opens with nothing ticked, a card sheet comes out with more or fewer cards than expected, the paper tray jumps back to a different tray, a Dunnage part that needs no label still queues one, or the application will not start from the MTM Loader, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
