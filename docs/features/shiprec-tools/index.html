ShipRec Tools

A collection of utility tools for the Shipping and Receiving team — including a live Material Availability Board and an Outside Service History viewer.

Overview

ShipRec Tools is a toolbox module. Unlike the other modules it does not capture new transactions — it presents useful cross-module views and utilities that help the Shipping and Receiving team make decisions in real time.

The tool selection screen lists available tools. Select any tool tile to launch it. Tools can be opened simultaneously in separate windows.

📊

Material Availability Board

Live view of incoming and outgoing material availability, including work order details and PO receiving status.

📋

Outside Service History

Search and review completed outside service requests — a read-only view of the data managed in the Outside Service module.

Material Availability Board

The Material Availability Board gives a live at-a-glance summary of parts that are expected or in progress — helping the team prioritize work and communicate with production.

Incoming Details view

Shows open PO lines from Infor Visual with expected delivery dates. Drill into any row to see the full PO line details, quantity ordered, quantity received to date, and remaining balance.

Work Order Details view

Shows open work orders from Infor Visual that are waiting on material. Each row displays the work order number, required part, required quantity, and the work order due date.

ℹ️
Read-only from Infor Visual. All data on the Material Availability Board is sourced directly from Infor Visual (SQL Server read-only connection). No data is modified by this tool.

Using the board

  1. Open ShipRec Tools → Material Availability Board.
  2. Use the tab bar to switch between Incoming and Work Orders.
  3. Click any row to expand the detail panel on the right.
  4. Use the search box to filter by part number or work order number.
  5. Press Refresh to reload data from Infor Visual.

Outside Service History

The Outside Service History tool is a read-only view of all completed outside service requests. It allows Shipping, Receiving, and supervisors to look up past requests without opening the Outside Service module.

Search options

  • Date range (required)
  • Request number (e.g., OS-000042)
  • Part number
  • Vendor name
  • Created by (person who submitted the request)

Columns displayed

  • Request number and creation date
  • Line number and part ID
  • Vendor and bill of lading number
  • Scheduled and actual ship date/time
  • Package count and quantity summary
  • Completion notes
ℹ️
Cannot edit from here. To correct a completed outside service record, use the Outside Service module and contact a supervisor.

Common Questions

The Material Availability Board shows stale data — how do I refresh?

Press the Refresh button at the top of the board. Data is pulled live from Infor Visual on demand and is not automatically refreshed in the background. There is no polling or scheduled refresh.

Can I export the Material Availability Board to Excel?

Not directly from this tool. For export-quality data, use the Reporting module which supports Excel export for receiving history. For production material data, run the equivalent report from Infor Visual.

A tool I used before is no longer on the selection screen — what happened?

Tools can be enabled or disabled by an Administrator in Settings. Contact your supervisor or administrator if a tool you rely on has disappeared from the selection screen.
