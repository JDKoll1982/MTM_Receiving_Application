🚚 Module

Volvo

Manage Volvo-specific dunnage shipments — create outbound shipment records, generate customer-compliant shipping labels, and track PO and receiver numbers through the shipment lifecycle.

Overview

The Volvo module handles the outbound side of dunnage management for Volvo accounts. When dunnage (e.g., returnable containers, trays, racks) is shipped back to Volvo, this module creates the shipment header, generates the required line-item records and labels, and tracks the subsequent PO and Infor Visual receiver number assignment.

Shipments are identified by a shipment date and a daily shipment number that resets to 1 each day. A shipment transitions from pending_po status to completed once a PO and receiver number have been entered.

ℹ️
Volvo-specific configuration required. Volvo master data (part numbers, components, customer-specific settings) is managed in Settings → Volvo. Ensure master data is up-to-date before creating shipments.

Shipment Lifecycle

1

Create Shipment

A new shipment header is created with today's date and the next available daily sequence number. Optional notes can be added.

Status: pending_po
2

Add Lines & Generate Labels

Volvo line items (parts and quantities) are added to the shipment. Label data is saved to the label data table for the operator to print via LabelView before the shipment leaves the dock.

3

Enter PO & Receiver Number

After the shipment is received by Volvo and a PO is issued, Purchasing enters the PO number and Infor Visual receiver number to close out the shipment record.

Status: completed
4

Archive

Completed shipments can be soft-archived (flagged is_archived = 1) to remove them from the active view while preserving the full historical record.

Creating a Shipment

  1. Click New Shipment on the Volvo home screen.
  2. Confirm the shipment date (defaults to today).
  3. Add optional notes about the shipment.
  4. Click Create — the shipment number is assigned automatically.
  5. Add line items (see Label Generation below).

Label Generation

Each line item on a Volvo shipment generates a label that meets Volvo's customer-specific labeling requirements. Labels include part number, quantity, shipment number, and other required fields.

Generated label data is written to volvo_generated_label_data and archived to volvo_generated_label_history after the shipment is completed.

ℹ️
Reprint from history. Labels can be reprinted from the volvo_label_history view in the Volvo module without modifying the original shipment record.

PO & Receiver Entry

After Volvo issues a purchase order for the returned dunnage, Purchasing enters the PO number and the Infor Visual receiver number against the shipment. This marks the shipment as completed.

  1. Open the shipment from the Pending PO list.
  2. Enter the PO number provided by Volvo / Purchasing.
  3. Enter the Infor Visual receiver number after receiving the PO in Visual.
  4. Click Save — status changes to completed.

Archiving

To keep the active shipment list manageable, completed shipments can be archived. Archiving sets is_archived = 1 on the volvo_label_data record. Archived shipments are hidden from the default view but remain queryable from the Archive search.

⚠️
Archiving is not deletion. Archived shipments and their label history are fully preserved in the database. Use the Archive filter in the Volvo home screen to view them.

Common Questions

The shipment number reset to 1 mid-day — is that normal?

The daily shipment number resets at midnight each day. If a new shipment is the first one created on a given date, its number will be 1 regardless of what the previous day's last number was. This is by design — the combination of date + number is always unique.

Can I edit a shipment after it is marked completed?

No. Once a shipment has a PO number and receiver number and is marked completed, it is read-only. Contact your supervisor if a completed shipment needs correction.

How do I find archived shipments?

Use the Show Archived toggle on the Volvo home screen. This adds archived shipments to the list alongside active ones, filtered by whatever date range you have set.
