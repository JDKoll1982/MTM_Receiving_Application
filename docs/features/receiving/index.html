📦 Module

Receiving

Log incoming materials against purchase orders, generate receiving labels, and build a permanent transaction history — all validated in real time against your Infor Visual purchase orders.

Overview

The Receiving module is used to record every pallet or shipment that arrives at the dock. Each transaction ties a physical quantity to a specific purchase order line in Infor Visual, creating a searchable record in the receiving_history database table. After saving, the operator prints labels separately using LabelView, which reads the data from receiving_label_data.

The application connects live to Infor Visual (read-only) to pull PO details, part descriptions, remaining quantities, and due dates. You do not need to retype information that already exists in the ERP — just scan or enter the PO number and the app fills in the rest.

🏷️
Quick label launch buttons are available from the workflow footer. Use Receiving Label or Mini-Receiving Label to open the configured LabelView template directly. If either the LabelView executable or the selected label path is missing, the app redirects you to the matching settings page.
ℹ️
Infor Visual connection required. If the app cannot reach the Visual database, PO lookups will fail. Contact IT if you see a "Cannot connect to Visual" error at login.

What gets recorded

  • Part number, quantity, and unit of measure
  • Purchase order number and line number
  • Package type and weight per package
  • Heat / lot number (when required by your quality rules)
  • Warehouse location (initial put-away location)
  • Employee number and date/time of the transaction

Entry Modes

When you open Receiving, the first screen you see is Mode Selection. Choose the entry mode that best fits what you need to do.

🧙

Guided Wizard

Step-by-step walkthrough. Each screen asks for one thing at a time. Best for learning the system or ensuring every field is filled correctly.

⌨️

Manual Entry

All fields on one screen. Experienced operators can tab through fields and save quickly without wizard navigation overhead.

✏️

Edit Mode

Load a previously saved receiving record to correct quantities, dates, or other details. Changes are tracked in history.

💾
Set a default mode. The checkbox under each mode tile on the selection screen lets you mark that mode as your personal default, so it opens automatically next time.

Guided Wizard

The Guided Wizard walks you through receiving a shipment one step at a time. The app validates your entry at each step before allowing you to continue, so nothing gets saved with missing or incorrect information.

1

PO Entry

Scan or type the purchase order number. The app searches Infor Visual and returns PO details — vendor name, open lines, due dates, and ordered quantities.

All POs require you to select the part from the list — even single-line POs. Part Selection is always shown so you can confirm the correct line before continuing.
2

Part Selection

Select the specific part number and PO line being received. The screen shows remaining quantity on order and the PO due date so you can confirm you are receiving the right item.

3

Load Entry

Enter the load or ASN reference that this shipment arrived on. This is used to group all labels from the same delivery together.

4

Weight & Quantity

Enter the quantity of parts on this pallet/skid and the weight per package. If you are splitting a shipment across multiple skids, use the Add Skid button to add additional quantity rows.

The remaining quantity from the PO is shown here as a reference. You can receive more than the remaining amount if needed.
5

Heat / Lot Entry

Enter the heat number or lot number printed on the material certification. This step is shown only when the part's settings require heat/lot tracking. It can be left blank if not required.

6

Package Type

Select how the material arrived — Skid, Box, Coil, Reel, etc. This is printed on the receiving label and recorded in history.

7

Review & Save

A summary of everything entered is shown before saving. Review each line and use the Edit links to go back and correct any field. When everything looks correct, press Save to Database to commit the transaction.

Saving writes label data to the receiving_label_data table. Labels are not printed automatically — the operator prints them separately using LabelView, which reads from that table.

Manual Entry

Manual Entry presents all receiving fields on one screen in a compact grid. It is designed for experienced operators who know the PO and part numbers in advance and want to move quickly without navigating through wizard steps.

When to use Manual Entry

  • Receiving multiple lines from the same vendor in one session
  • Quick re-entry when you have a printed packing slip in front of you
  • Situations where the guided wizard feels slower than necessary
⚠️
Validation still applies. Manual Entry runs the same PO and part number lookups as the Guided Wizard. Invalid PO numbers or unrecognized part numbers will be flagged before saving.

Edit Mode

Edit Mode lets you load a previously saved receiving record and make corrections. Use it when a transaction was saved with a wrong quantity, incorrect package type, or a typo in the heat/lot number.

How to edit a record

  1. Select Edit Mode on the Mode Selection screen.
  2. Search for the record by PO number, part number, or date.
  3. Select the record from the results list.
  4. Make your changes on the edit form.
  5. Save — the original record is updated and a change log entry is written.
⚠️
Edit Mode may require Supervisor access. Depending on your facility's settings, editing historical records may be restricted to Supervisors or Administrators. Contact your supervisor if the Edit Mode tile is greyed out.

Keyboard Shortcuts

Keyboard shortcuts let you navigate the receiving workflow without touching the mouse. All shortcuts are configurable in Settings → Receiving → Keyboard Shortcuts.

Advance to next step Ctrl →
Go back to previous step Ctrl ←
Return to mode selection Ctrl M
Clear label data Ctrl Shift C
ℹ️
The defaults shown above are the factory defaults. Your administrator or you (in Settings) may have changed these. The actual shortcuts in effect are always visible at the bottom of the receiving workflow screen.

Common Questions

The PO number I scanned doesn't show up — what do I do?

First, confirm the PO number on the packing slip matches exactly what you entered (no extra spaces or hyphens). Infor Visual PO numbers are case-sensitive.

If the PO still isn't found, check with Purchasing to confirm it has been released in Infor Visual. Unreleased or closed POs will not appear in the lookup.

I scanned the wrong PO and have already moved to Part Selection. Can I go back?

Yes. Use the Back button at the bottom of any wizard step, or press Ctrl ← to return to the previous step. Nothing is saved until you press Save to Database on the Review screen.

Is the transaction saved even if the label wasn't printed?

Yes. Saving and printing are separate steps. The app writes the data to receiving_label_data when you save — labels are not printed automatically. The operator prints them using LabelView, which reads from that table. If a label was never printed, the data is still in the database and can be printed at any time from LabelView.

What does "Quality Hold" mean on the Review screen?

A Quality Hold flag appears when your quality rules require an explicit acknowledgment before a particular part can be received. You must check the acknowledgment checkbox on the Review screen to enable the Save button. This does not stop the receiving — it just creates an audit record that the hold was acknowledged.

Can I receive a part that isn't on a PO?

Yes, through the Non-PO Entry option. This is available in Manual Entry mode and in the Guided Wizard when a PO number is left blank. Non-PO items are flagged with is_non_po_item = 1 in the database and appear in Reporting with a distinct indicator.

How do I receive the same part across multiple skids?

On the Weight & Quantity step, use the Add Skid button to create additional quantity rows. Each row produces a separate label with a sequential skid number (1 of 3, 2 of 3, etc.).

My session timed out mid-receiving — was anything saved?

Nothing is written to the database until you press Save to Database on the final Review screen. If you were timed out before reaching that screen, no data was saved. You will need to re-enter the transaction from the start.
