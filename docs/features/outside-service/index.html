🔧 Module

Outside Service

🚧
In Development — not available in the current release. This module is disabled in the application. The documentation below reflects the planned design and may change before launch.

Create and track requests to ship parts to an outside vendor for processing (plating, heat treat, machining, etc.) and manage the full lifecycle from initial request through shipping and completion.

Overview

When a manufactured part needs to go to an outside vendor for a service operation (e.g., heat treatment, plating, grinding), the Outside Service module manages the paperwork and tracking. Each request is identified by a human-readable request number in the format OS-000001.

A request contains one or more lines. Each line represents a specific part going to a specific vendor. Each line can have multiple packages describing how the parts are physically split across containers.

ℹ️
Three-table data model. Requests → Lines → Packages. A request groups the shipment; lines identify the parts; packages describe the physical containers.

Request Lifecycle

Each line on a request moves through three phases:

1

Initialize

The line has been created. The part, package count, and quantity per package have been entered by the requestor. The line is waiting for Shipping to pick it up.

2

Setup

Shipping has taken ownership of the line. They have entered the vendor, bill of lading number, scheduled ship date, and shipping contact. The line is ready to ship.

3

Complete

The shipment has left the building. A completion timestamp and optional completion notes are recorded. The line is closed.

Creating a Request

Anyone with access to the Outside Service module can create a new request. The request number is assigned automatically in OS-NNNNNN format.

Steps to create a new request

  1. Click New Request on the Outside Service home screen.
  2. Optionally add request-level notes for Shipping (e.g., "Priority — needed by Friday").
  3. Click Add Line for the first part.
  4. Enter the Infor Visual part number.
  5. Enter the number of packages and the quantity in each package.
  6. Repeat steps 3–5 for additional parts on the same request.
  7. Click Submit Request to save it and make it visible to Shipping.
ℹ️
Part validation. Part numbers are validated against Infor Visual when entered. Parts not found in Visual will be flagged — confirm the part ID with Engineering before submitting.

Shipping Setup

When Shipping is ready to process a line, they open the request, select the line, and advance it to Setup phase. During setup they enter:

  • Vendor — selected from Infor Visual vendor history or entered manually
  • Bill of Lading number — assigned by the carrier
  • Scheduled ship date/time
  • Shipping contact — person handing off the shipment
  • Setup notes — any special instructions for the vendor

Completing a Line

Once the shipment has physically left, Shipping marks the line as Complete. This records a UTC completion timestamp and locks the line from further edits.

A completion note can be added to document anything unusual about the shipment.

⚠️
Completion is final. Once a line is marked Complete it cannot be re-opened through the normal UI. Contact a Supervisor or Administrator if a completed line needs to be corrected.

Common Questions

Can I add a line after a request has already been submitted?

Yes, as long as no lines on the request are in Setup or Complete phase. Open the request and use Add Line to append a new line. Once any line has been picked up by Shipping, the request header is locked for new lines.

What if the vendor changes after Setup?

A Shipping user can edit the Setup fields (vendor, BOL, scheduled date) as long as the line is still in Setup phase. Once the line is marked Complete, vendor information is locked.

Where can I see all open outside service requests?

The Outside Service home screen lists all requests that have at least one line in Initialize or Setup phase. Fully completed requests can be found using the date-range search on the same screen.
