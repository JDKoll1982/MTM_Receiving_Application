📋 Module

Dunnage

Receive, track, and manage dunnage — the packaging materials (pallets, dividers, boxes, reels, and more) that arrive with your parts shipments.

Overview

Dunnage refers to the protective and structural packaging that comes in with inbound shipments. The Dunnage module lets you log each receipt, associate it with a purchase order or mark it as a non-PO item, record quantities and specifications, and generate labels — all in one workflow.

Every completed transaction is written to the dunnage_history table, preserving a snapshot of the type, quantity, specs, and who processed it.

What the module tracks

  • Dunnage type (Pallet, Corrugated Divider, Coil Reel, etc.)
  • Specific part number and its associated specifications
  • Quantity and the unit of measure for that type
  • PO number (optional — non-PO items are supported)
  • Warehouse location
  • Per-line dynamic specs captured as JSON
  • Who received it and when
ℹ️
Types and parts are managed in Settings. Administrators set up dunnage types (e.g., "Pallet") and the specific parts within each type (e.g., "GKN-48x40 Wood Pallet") in Settings → Dunnage before operators can receive them.

Entry Modes

Choose the entry mode that fits your workflow on the Mode Selection screen.

🧙

Guided Wizard

Step-by-step screens for selecting type, part, quantity, and details one at a time. Recommended for new operators.

⌨️

Manual Entry

All fields on one grid-style screen. Faster for operators who already know the type and part numbers.

✏️

Edit Mode

Load a historical dunnage record to correct quantities, dates, PO numbers, or specs.

🖼️

Image Part Search

Browse an image catalog to identify dunnage parts visually, then hand off into the standard guided flow.

Guided Wizard

The Guided Wizard walks through dunnage entry one step at a time. Each step is validated before you can advance.

1

Type Selection

Choose the category of dunnage — Pallet, Divider, Box, Reel, etc. The types shown here are configured by your administrator. Each type tile shows its icon and name.

2

Part Selection

Select the specific dunnage part within the chosen type. Parts have names, part IDs, and can include images to aid identification. Use the search box to filter if there are many parts in a type.

Can't find the part visually? Use Image Part Search mode from the Mode Selection screen to browse photos and auto-select the part.
3

Quantity Entry

Enter how many units of this dunnage part arrived. The quantity label (e.g., "Quantity", "Pieces", "Bundles") is set per-type in Settings and is shown above the entry field.

4

Details Entry

Enter additional information: PO number (optional), warehouse location, and any per-type custom specification fields configured by your administrator.

Location is required when your settings enforce it. Check with your supervisor if the field appears greyed out or mandatory.
5

Review & Save

A summary of all entries is displayed. Confirm the details and press Save to write the transaction to history and prepare label data for printing.

Manual Entry

Manual Entry presents a compact grid where you can add multiple dunnage lines at once before saving. Each row represents one dunnage receipt item.

When to use Manual Entry

  • Processing several different dunnage types from the same delivery
  • When you have a packing slip with all the information already written down
  • For high-volume, repetitive receiving where wizard navigation slows you down
⚠️
All rows are saved at once. In Manual Entry, nothing is committed until you press Save All. If you close the screen before saving, all entered lines are lost.

Edit Mode

Edit Mode loads historical dunnage records so you can correct mistakes after a transaction has been saved. Search by date range, part, or the person who originally entered the record.

Editable fields

  • Quantity
  • PO number
  • Location
  • Received date
  • Dynamic spec values
⚠️
Edit Mode may require elevated access. Contact your supervisor if the Edit Mode option is not visible on the Mode Selection screen.

Image Part Search

Image Part Search is a visual catalog that lets you identify a dunnage part by looking at photos rather than reading part numbers. This is especially useful when a shipment arrives without clear labeling.

How it works

  1. Select Image Part Search on the Mode Selection screen.
  2. Browse the photo grid — each card shows the dunnage part image, name, and type.
  3. Tap the part that matches what arrived.
  4. The app hands you off to the standard Guided Wizard with the type and part pre-selected.
  5. Continue from the Quantity Entry step as normal.
ℹ️
Images are uploaded and managed by your administrator in Settings → Dunnage → Image Assets. If a part has no image assigned, it will not appear in Image Part Search.

Review & Save

The Review screen (final step in the Guided Wizard) shows a complete summary of everything entered. You can use the Edit links next to any field to jump back and correct a value.

When you press Save to Database, the app:

  1. Writes a row to dunnage_history.
  2. Writes label data to the label data table for LabelView to consume.
  3. Returns you to Mode Selection for the next transaction.
ℹ️
Printing is a separate step. The app saves label data to the database — the operator prints labels using LabelView, which reads from that table. The transaction is always saved regardless of whether printing has occurred.

Common Questions

The type I need isn't listed — what do I do?

Types are managed in Settings → Dunnage → Category Management. Contact your administrator or supervisor to have the new type added. Until it is added, use the closest matching type and note it in the transaction comments if available.

Can I receive dunnage without a PO number?

Yes. The PO number field on the Details Entry screen is optional. Transactions without a PO number are stored with a NULL po_number in dunnage_history and can still be searched and reported on.

I added a row in Manual Entry but it disappeared — why?

In Manual Entry, rows exist only in the session until you press Save All. Navigating away, timing out, or closing the app before saving will discard all unsaved rows. Make sure to save before leaving the screen.

Where can I see what dunnage was received this week?

The Reporting module provides date-range queries. You can also use Edit Mode to search dunnage_history by date and view results without making any changes.
