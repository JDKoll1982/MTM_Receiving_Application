🗄️ Table

outside_service_request_package

Individual package records for each outside service request line. Each row is one physical container (box, pallet, etc.) with its own quantity of parts.

Overview

When parts are split across multiple containers for a single outside service line item, each container becomes one row in this table. The package_number provides a 1-based sequence within the line.

The parent line's package_count and package_summary are derived from these rows and cached on the parent when packages are saved.

Columns

ColumnTypeNullableDescription
outside_service_request_package_idINT PK AUTONoSurrogate primary key
outside_service_request_line_idINT FKNoParent line (CASCADE DELETE)
package_numberINTNo1-based package sequence within the line
quantity_in_packageINTNoNumber of parts in this container

Usage Notes

  • A unique constraint on (outside_service_request_line_id, package_number) prevents duplicate package numbers within a line.
  • After inserting or deleting package rows, the app refreshes the parent line's package_count and package_summary fields.
  • Sum of quantity_in_package across all packages for a line equals the total quantity being shipped for that line item.
