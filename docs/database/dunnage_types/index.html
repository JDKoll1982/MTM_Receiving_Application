🗄️ Table

dunnage_types

The lookup table that categorises dunnage — the packaging materials (boxes, pallets, containers, dividers) that arrive with parts shipments. Every dunnage part belongs to exactly one type.

Overview

This is a small, slow-changing master table. Each row describes one kind of dunnage, its display icon, and an optional image. The dunnage type is what the operator picks first when receiving dunnage; the specific part is chosen within that type.

Rows are referenced by dunnage_parts.type_id. Type names are snapshotted onto dunnage_history rows when a load is archived, so history keeps the name that was in use at the time even if it is later renamed.

Usage Notes

  • Deleting a type that any dunnage_parts row still references is blocked by a RESTRICT foreign key — reassign the parts first.
  • icon must be a valid MaterialIconKind name; the app renders it directly and shows nothing for an unknown value.
  • image_path is relative to the app-managed dunnage image folder, not an absolute or web path.
  • Renaming a type does not rewrite history — dunnage_history.type_name keeps the name snapshotted at archive time.
