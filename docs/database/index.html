🗄️ Reference

Database Reference

All MySQL tables used by the MTM Receiving Application — grouped by functional area. Each table page includes the full column list, indexes, and usage notes.

ℹ️
MySQL only. These tables are in the mtm_receiving_application_test database on the local MySQL 5.7 server. Infor Visual (SQL Server) tables are READ ONLY and are not documented here — see the CSV schema files in docs/InforVisual/DatabaseCSVFiles/.

📦 Receiving

TableDescription
receiving_history Permanent ledger of all completed receiving transactions
receiving_label_data Active queue for in-progress receiving sessions; rows promoted to history on completion
receiving_package_types Remembered package type preference per part number
receiving_package_type_mapping Maps package type names to label template codes
receiving_quality_holds Quality hold records tied to receiving transactions

📋 Dunnage

TableDescription
dunnage_typesMaster list of dunnage container types
dunnage_partsParts that require dunnage containers
dunnage_historyCompleted dunnage transaction history
dunnage_requires_inventoryDunnage items that track inventory levels
dunnage_specsDunnage container specifications per part
dunnage_custom_fieldsUser-defined custom fields for dunnage types
dunnage_non_po_entriesDunnage entries not linked to a PO
dunnage_label_dataLabel print queue for dunnage
dunnage_quantity_typesQuantity type definitions (individual, pallet, etc.)
