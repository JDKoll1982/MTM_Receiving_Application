🗄️ Table

outside_service_request_line

Line items within an outside service request. Each row is one part destined for one vendor. Tracks the full lifecycle from Initialize through Setup to Complete.

Overview

Lines are the operational heart of the Outside Service module. The line_phase ENUM drives the UI state machine — fields become editable or read-only depending on the current phase.

Each line can have multiple packages (see outside_service_request_package). A cached slash-delimited summary of those packages is stored in package_summary for fast display without a join.

Usage Notes

  • The line_phase ENUM is the state machine driver. Only fields appropriate for the current phase are editable in the UI.
  • package_summary is a denormalized cache — always refresh it when the child packages change.
  • Setup fields (setup_vendor_*, bol_number, etc.) are NULL until the line enters Setup phase.
  • Completion fields (completed_utc, completion_notes) are NULL until the line enters Complete phase.
