🗄️ Table

outside_service_request

Header table for outside service requests. One row per request. The human-readable request_number (format OS-000001) is unique and used for all display and search operations.

Overview

Each outside service request is a container for one or more lines (stored in outside_service_request_line). The header captures who created the request and any request-level notes for Shipping.

There is no status field on the request header itself — the aggregate status of the request is derived from the line_phase values on its child lines.

Usage Notes

  • Use request_number for all user-facing lookups and display — it is unique and indexed.
  • The request-level status (open / partially complete / fully complete) is computed on the fly from child line phases — it is not stored on this row.
  • Child lines are deleted (via CASCADE) if a header row is deleted. The application does not delete headers through normal workflow — deletion would only occur as an administrative correction.
