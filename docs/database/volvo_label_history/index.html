volvo_label_history

A permanent archive of Volvo shipments that have been cleared from the active queue. Unlike the live table, nothing here is ever edited — it is the record of what was shipped and when it was cleared.

Overview

When an operator runs Clear Label Data, completed shipments are copied out of volvo_label_data into this table and flagged archived in the source. Each archived row keeps its original primary key in original_id so it can always be traced back.

Every row carries an archive_batch_id — a UUID shared by all the rows cleared in the same operation. That makes one Clear run a single, auditable unit.

Usage Notes

  • This table is append-only in normal use. Rows are written by Clear Label Data and should not be edited afterwards.
  • archived_at is when the row was cleared; shipment_date is when the shipment actually occurred. Report on the business date.
  • archive_batch_id is the practical way to audit or reverse a single Clear operation — every row from that run shares the same UUID.
  • status is a plain string here rather than an enum, so it can hold whatever value existed at archive time.
  • Line-level detail is not copied into history — to reconstruct the parts on a shipment, join back to volvo_line_data using original_id while the lines still exist.
