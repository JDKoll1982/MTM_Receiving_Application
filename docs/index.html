MTM Receiving Application

Developer and maintainer reference for the WinUI 3 desktop application used by the manufacturing floor to manage receiving, dunnage, outside service, and Volvo EDI workflows.

Feature modules

📦 Receiving PO lookup, label generation, quantity tracking, quality holds, and receiving history. 📋 Dunnage Container tracking, dunnage specs, inventory management, and label printing. 📊 Reporting On-demand and scheduled reports, Excel exports, and email delivery. 🔧 Outside Service Create, track, and complete outside service requests across Initialize → Setup → Complete phases. Not yet available in the current release. 🚚 Volvo EDI-driven receiving workflow, AIAG barcode scanning, and Volvo-specific label generation. 🛠️ ShipRec Tools Shipping and receiving utility tools, pack slips, and shared cross-module helpers.

Reference

🗄️ Database Reference MySQL table schemas, column definitions, indexes, and usage notes for all tables. 🆕 Updates Release notes for each version — what changed, why it matters, and what users need to do. 🎓 End-User Help Step-by-step guides for operators — mode selection, PO entry, quality holds, and label printing.
