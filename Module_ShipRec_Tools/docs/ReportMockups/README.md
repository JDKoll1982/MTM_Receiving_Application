Last Updated: 2026-05-20

## Purpose

This folder contains the full first-pass HTML mockup package for the **Customer Pull n' Pack** feature.

It includes:

- package-definition markdown files
- visual-direction markdown files
- a shared HTML/CSS/JS mockup foundation
- complete HTML mockup pages for report, waitlist, settings, empty-state, and print flows
