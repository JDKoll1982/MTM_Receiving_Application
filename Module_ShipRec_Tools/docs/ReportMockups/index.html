Customer Pull n' Pack Mockups

Complete first-pass review package for the Customer Pull n' Pack feature, including report, waitlist, settings, empty-state, and print flows.

WinUI 3 aligned CommunityToolkit aware HTML review package MTM shell preserved

Overview

This package is built from the current feature spec and prompt, with the waitlist treated as a separate entity from the report and the material handler working primarily from a dedicated waitlist page.

ℹ️
Review intent. These files are complete HTML mockups for review. They are not implementation code, but they intentionally use realistic WinUI and CommunityToolkit-style control choices.
