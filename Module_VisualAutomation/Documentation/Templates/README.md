# Templates

Last Updated: 2026-11-11

This folder is for document templates that the rest of this documentation tree is copied from. It is empty
by design: the module's own pages must stay short, and a template that nobody copies is worse than none.

Put a file here only when you are about to reuse it at least twice. Useful candidates:

- **Probe addition checklist** - the catalogue entry, the switch arm, the two count assertions, and the
  live run, copied from [Daily Tasks](../How-To-Guides/Daily-Tasks.md) task 1.
- **Change-Log entry** - date, what changed, files touched, evidence a reviewer can re-check.
- **Support case note** - symptom, verdict text, snapshot lines, VISUAL state, outcome.

Rules for anything added here:

- Keep it under 60 lines and free of project-specific facts; facts belong in the page that uses them.
- Every file starts with a `#` heading and a `Last Updated: YYYY-MM-DD` line within the first five lines.
- No secrets, no connection strings, no customer data.
