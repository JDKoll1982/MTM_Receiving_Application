# Quick Start

Last Updated: 2026-11-13

## In one minute

1. Open **Receiving Validator** from the Reporting group.
2. Choose **Work a Receiving Day**.
3. The day opens on today. The top strip tells you how many lines were scanned and how they came out.
4. Pick a line. The right-hand pane explains what the module found and fills in the destination it proposes.
5. Press **Enter** to accept it, or **Escape** to skip it. A skipped line is only skipped for this session. An accepted line leaves the list at once, and its group header goes with its last line.
6. If the button marked **Needs Attention** is lit, something needs you: open it, read the reason, type a location, and set it.

## The colours

- **Green** — the line was changed and written.
- **Blue** — the line is ready to accept.
- **Amber** — the movement shows more material than the lines account for.
- **Red** — the lines ask for more material than the movement delivers.
- **Grey** — the line was skipped, or nothing was found for it.
- **Teal** — you set the location by hand.

## What "not writable" means

The module will not let you write a line it cannot fully account for. That is deliberate: a wrong location is worse than a location left alone. The reason in the pane tells you what is missing.

## Days with nothing on them

Use **Previous** and **Next**, which skip days with no receiving rows. **Today** brings you back.
