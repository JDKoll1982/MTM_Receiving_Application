# Templates

Last Updated: 2026-11-12

Placeholder folder for document templates this module may need later.

No template is in use yet. When one is added, copy it here and name it after the document it produces, for example `Template-Change-Log.md`.

Until then, follow the shapes the existing files use:

- an overview that says what the module is for and what it is not for
- a how-to that is a numbered list of actions
- a change-log entry that states what changed, why, and how it was verified
- a decision entry that states the decision, the evidence, and what was rejected
